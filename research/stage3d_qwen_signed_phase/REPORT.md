> 2. **关键科学澄清（不可将形式显著误读为真正的外推物理建模能力）**：
>    - 在主格 `G1` 上，**两臂的绝对准确率与 NLL 均劣于四选一随机猜测（`25.00% / 1.3863`）**，仅达同缓存 CPU 物理读出（`64.62%`）的约三分之一。
>    - 结合 2×2 探索格（第 3 节）与 Work F 机制探针（第 4 节）可见：在训练累计转角 $|ω|(h+\ell) \le 1.25\text{ rad} < \pi/2$ 的支持域内（`G2` 与 `G4`），**`zero` 对照臂反而显著高于 `phase` 臂（`G2`: `36.36%` vs `33.88%`）**；而一旦进入累计转角 `1.60 rad > π/2` 的强外推区（`G1` 与 `G3`），未学会“跨 $90^\circ$ 象限折返”的两臂均跌破随机线，其中在支持域拟合更锐利的 `zero` 臂因反相关预测跌得更深（`19.41%` / `19.74%`），而 `phase` 臂因仅学会了微弱的物理方向响应（`gain = +0.0098`）加上略微保守的局部预测，少跌了约 3–4 个百分点。
> 3. **核心机制两问的直接回答**：
>    - **宿主概率是否朝物理上正确的方向移动？** **是，但效应极弱。** 在 `±0.40` 下 `phase` 对匹配物理对比度的方向增益仅 `+0.0098`（约为理想物理参考 `1.0` 的 1%），交换告知符号使 NLL 劣化 `+0.0184 nats`；虽明显强于 `zero` 臂（增益 `+0.0050`、交换劣化 `+0.0074 nats`），且单模态矛盾探针证明宿主对 6 个连续数值相位槽的敏感度（翻转相位槽引起 `TV = 0.0371`）高于对中文频偏文本数字的敏感度（翻转文本引起 `TV = 0.0281`），但两者均未形成有效的 $\pi/2$ 跨象限三角旋转算子。
>    - **宿主是否辨认出迟到导频 Q2 的新证据？** **尚未成功辨认第二次独立采样的新增信息。** 在未见 `C4`（`ω = +0.35, t_p = 4`）条件上，物理核从单次有效导频到两次独立重采样的准确率显著跃升 `+7.81 pp`（`66.41% → 74.22%`, `NLL 0.8192 → 0.6632`）；而 Qwen 相位臂在加入 `valid` 导频后虽较 `none` 略有上升（`24.80% → 28.78%`, `+3.97 pp`，但 NLL 微升 `-0.0040`），再加入第二条独立有效采样 `fresh_resample` 后准确率反而回落 **`-2.34 pp`**（`28.78% → 26.43%`, `NLL 1.3889 → 1.4056`）；`zero` 臂亦表现为 `valid 26.63% → fresh_resample 25.78%`（`-0.85 pp`）。

### 1.2 工程关键排查：Qwen3.5 混合线性注意力引用环与 BF16 批并行数值一致性

1. **参照引用环导致的 `71.64 GiB` OOM 定位与根治（[qwen_connector.py](qwen_connector.py)、[bench_steady.json](results/bench_steady.json)）**：
   - 初版 `_make_differentiable_qwen35_cache()` 将闭包 `_update_conv(..., _l=layer)` 绑定至每层 `LinearAttentionLayer` 实例，在 Python 中制造了 `layer -> update_conv_state -> _l -> layer` 直接引用环；当 `cand_out` 在 `use_cache=False` 仍触发 `cache.update_recurrent_state` 写入计算图张量后，连续微批的激活图无法被引用计数即时回收，最终在首轮 Seed 1 尝试中飙升至 `71.64 GiB` OOM。
   - **修复方案**：改用模块级缓存子类 `_OutOfPlaceLinearAttentionLayer(LinearAttentionLayer)` 切换 `layer.__class__`（零实例闭包引用环），同时使用原生 `F.log_softmax(..., dim=-1, dtype=torch.float32)` 避免全词表 `.float()` 复制，并在 `cand_out` 前及时 `del pref_out, out_cache, pref_cache`。
   - **实测验证**：在最长输入组 `Q3_after_pilot`（`351` 字符 + `1` 条参考）与 `Q2_fresh_resample`（`2` 条参考）上连跑 4 个微批，分配显存严格恒定为 **`[8055.2, 8055.2, 8055.2, 8055.2] MB`**（零泄漏）；`micro_batch_size=16` 训练峰值稳定在 **`52,972.5 MB`**（稳态 `1,975.7 ms / 32-ex step`），盲测推理 `b=64` 峰值 **`45,409.9 MB`**（`23.88 ms/例`）。
2. **`bfloat16` + FLA 核的批大小一致与跨批差异透明报告（[direct_vs_table_parity.json](results/direct_vs_table_parity.json)）**：
   - 在与 256 查表完全相同的 **`matched_batch_size = 64`** 条件下，直接前向与 256 查表在 G1 盲测 256 条抽样核对中取得 **`max_abs_ll_diff = 0.0`**、**`max_abs_prob_diff = 0.0`**、**`argmax_agreement = 1.0`**（4 组 `(arm, ±0.40)` 全部精确为零）。
   - 同时记录了跨批大小的 BF16/Triton 矩阵分块舍入噪声：在训练前随机权重上（`bench_steady.json`），`b=1/16` 与 `b=64` 的 `max_abs_ll_diff` 为 `0.4816–0.4830`（`argmax_agreement = 1.0`）；但在训练后预测高度接近均匀的盲测模型上（`direct_vs_table_parity.json` 中 `cross_batch_b16_vs_b64`），`b=16` vs `b=64` 虽 `max_abs_ll_diff` 降至 `0.115–0.289`（`max_abs_prob_diff = 0.024–0.067`），但因近四选一均分边界细微扰动，导致 `argmax_agreement` 在 `phase -0.40` 为 `0.6875`（`phase +0.40: 0.8750`, `zero -0.40: 1.0000`, `zero +0.40: 0.9375`）。全盲测统一度量（表生成与全盲测前向）均统一运行在固定 `batch_size = 64` 下，确保内部严格自洽。

## 2. 两臂对照设置、6 次训练过程与样本量盲前锁定

### 2.1 六个数值槽设计与零泄露契约

- 以第一窗为时间零点 $t_1 = 0$，分别取 $t \in \{h, h+\ell, t_p\}$ 计算 6 维实数值槽：
  - **`phase` 相位臂**：$[\cos(\omega h), \sin(\omega h), \cos(\omega(h+\ell)), \sin(\omega(h+\ell)), \cos(\omega t_p), \sin(\omega t_p)]$；
  - **`zero` 对照臂**：$[0, 0, 0, 0, 0, 0]$；
  - **严格共享控制**：除这 6 个槽外，相同的 `phase_mlp` 结构、相同的 `(z1, z2)` 编码缓存、相同的中文题面与有符号 $\omega$（例如 `omega=+0.40rad/步` 或 `-0.40rad/步`）、相同的硬物理扇区标签、相同的训练样本顺序与优化器预算，彻底排除真实布朗路径、未揭示导频与工况 ID 标签。

### 7.4 本轮最值得继续追查的核心观测

> **最值得优先追查的观测：为何跨过累计转角 $\pi/2$ 边界（$|ω|(h+\ell) = 0.80 \rightarrow 1.60\text{ rad}$）后两臂均出现急剧断崖，且当前加性连续 `<PHASE>` token（1,280 步）只诱导出 `+0.0098`（物理参考约 1%）的微弱方向增益？**
> - 实验揭示，只要把 `|ω|` 提高到 `0.40` 但缩短延迟使总转角留在 `0.80 rad`（`G4`），宿主的准确率就能维持在 `33.3% / 35.0%`；而一旦保持已知频率 `|ω| = 0.20` 仅拉长延迟使总转角越过 $\pi/2$ 到达 `1.60 rad`（`G3`），宿主立即跌回 `22.7% / 19.7%`，甚至在典型单缓存样例上给出与真值完全对角反指（扇区 0 vs 扇区 2）的自信判决。
> - 原因直指结构感应偏置：**把 `[cos(ωt), sin(ωt)]` 经过独立 MLP 编码为 3 个追加在序列尾部的加性 `<PHASE>` 软 token，仍要求冻结语言模型自己通过跨注意/线性状态衰减去“手算”连续三维旋转对离散 `(z1, z2)` 表征的调制，这既拖慢了支持域内的收敛（解释了为何 `G2/G4` 上 `phase` 落后 `zero` 约 `2 pp`），又无法保证 $\text{SO}(2)$ 等变群外推。** 后续最自然也最干净的对照实验是：将 `[cos(ωt), sin(ωt)]` 从外挂加性 token 升级为连接层内部的**显式低维双线性/复旋转调制**（在传入冻结宿主之前将编码器特征按公开相位角预先旋转或与相位基做群协变耦合，或将训练支持稍微跨过 $\pi/2$ 如 $|\omega|(h+\ell) \approx 1.8$ 区分“表示欠约束”与“支持未覆盖”）。
