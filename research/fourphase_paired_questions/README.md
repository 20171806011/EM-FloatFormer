# 同一段四相波形上的配对题

**这一轮测两件事：波形哪一段决定相对相位，以及同一个参考出现两次时，接收机能否保持正确的置信度。** 这是总计划阶段二的合成小基准，沿用[上一轮的两道问题](../fourphase_memory_pilot/README.md)。使用复数波形和明确的四相先验，比较表示与解析读出。正式训练的编码器和真实会话留出是后续阶段。

## 先固定每对题的正确关系

对一条母记录生成三个版本。数据窗包含噪声，对整个已接收窗口乘以 $i$，所以每个复样点的幅度、噪声实现的模、窗长与采样位置逐点匹配。两个问题的文字固定。生成器采用独立均匀四相的两个发射标签及公共旋转。以下主实验在同一接收坐标系中转动数据窗口，保持导频不动；相应反事实的发射标签也随被转的数据窗口改变。收到参考以前就提交第一问的四项概率。

| 观测版本 | 第一问：第二个发射符号相对第一个转了多少 | 第二问：给定同一有效导频，第一个发射符号是什么 |
|---|---|---|
| 原波形 | 原分布 | 原分布 |
| 只将第二窗转 90° | 概率向前循环移一格 | 概率逐项相同 |
| 两个数据窗同转 90°，导频固定 | 概率逐项相同 | 概率向前循环移一格 |

另设坐标检验：若两个数据窗和导频一起转了 90°，这是整套接收坐标变化，两道题都应保留原来的分布。对独立参考或无参考，第二问的后验均匀，旋转均匀分布不会改变它。

每个波形版本配四种参考条件，合为每个母本十二种组合：

- 没有参考。独立均匀的公共旋转使首符号四个标签等可能。
- 一个有效参考。用共享相位的似然更新四个首符号标签；有效样本也可能在某一帧把正确标签的概率降低。
- 一个已知独立的参考。它具有与有效参考相同的单独观测分布，对目标的四项后验应与无参考一致。
- 将同一有效参考逐样点原样呈现两次。第二次连噪声都相同。比较一次、两次的四项后验，每一项都应相同。

接收器在指定条件下知道参考是否共享信道、两个副本是否引用同一次采样。母本编号、答案、旋转版本和用于汇总的条件名称不作为预测特征。若将参考来源也隐藏，任务就有另一套正确答案：本例有效与独立条件的可见观测边缘分布相同。有效参考的先验比例若为 $\pi$，正确的首符号后验为 $\pi p_{\rm valid}+(1-\pi)/4$ （逐个标签计算）。仅凭这两个窗口和一个导频样本，不能对每帧可靠地辨别来源。

## 可手算的一对题

观测取 $Y_1=1,Y_2=i$。正确相对角为 90°，只转第二窗得到 180°，从原波形把两窗都转动则回到 90°。数据无噪，单位导频的**接收相位标签**有 5/8 的概率正确，其余三个象限各占 1/8。观察到导频为 1 时：

| 条件 | 首符号为 1 的概率 |
|---|---:|
| 无参考或同样显示为 1 的已知独立参考 | 1/4 |
| 单个有效参考 | 5/8 |
| 完全重复该有效参考 | 5/8 |
| 反例：把这个副本误当成新的独立测量 | 25/28 |

最后一种处理连概率最高的标签都没有改变，置信度却明显错了。这就是为什么这里需要比较整组概率。[离散精确核查](exact.json)

## 验收与下一步

以母波形为单位划分，所有派生版本属于同一划分。对同一帧逐项计算概率是否发生规定的平移或保持，另看真实标签上的准确率和对数损失。报告相位可用的解析解、只看幅度及每窗各自消掉相位后的结果。只报告“不变”会让永远输出均匀概率的系统也得满分；第一问的正确方向、概率分辨能力和标签评分应同时通过。先把这些输入和评分固定，后续在同一批测试母本上比较等预算编码器；再用真实录制的已知序列检验可迁移的预测。

## 本次合成复算

开发集 256 条母波形，测试集 1,024 条，分别使用不同的随机种子。每 64 条母本平衡全部两个发射标签和公共相位的组合；每窗三个复采样，按整窗信号能量计的信噪比为 2 dB。独立参考用一个独立均匀的象限旋转母导频（包含同一噪声实现）构造，因此与有效参考逐点等幅，边缘分布与有效参考相同，而且相对于数据窗的公共相位独立。两个参考臂共享同一条噪声实现以便配对，不会同时交给同一方案。逐窗去相位基线利用首个非零样点固定该窗方向；在均匀四相模型下，该表示和纯幅度都对各窗旋转不变，其给定标签的分布完全相同，因此两者的解析最优输出均匀。

1,024 条测试母波形各给出 12 种组合。在复数解析解上，第一问正确率为 70.61%；已声明无关参考与无参考的第二问正确率均为 25.00%，有效与重复参考均为 68.75%。所有规定的后验旋转关系和重复后验逐项通过。若把一个副本当作另一次独立接收，第二问四项概率同正确解的平均总变差距离为 0.07691（按原始波形计）。在三个旋转版本合计 3,072 个配对中，用最小标签打破无参考下的四方平局，揭示有效参考后纠正 1,580 次，也新增 236 次错误。各版本共用母本，3,072 并非独立样本数。此处只比较可解析的输入表示，尚待检验训练后的模型如何答题。[开发结果](dev.json) · [测试结果](test.json)

Python 3.9+ 标准库即可复跑：

```sh
python3 check_discrete.py
python3 paired.py --split dev
python3 paired.py --split test
python3 paired.py --split test --cases > paired_test.jsonl
```
