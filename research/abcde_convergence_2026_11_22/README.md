# EM-FloatFormer 五组会合与接收机配对实验

同一微型输入上，A 的联合枚举与 Python 修正给出的最终位概率最大相差 **1.95×10⁻¹⁵**。显式删除目标边际在两帧时域 CFO＋ICI 合成样本上救回 9 位、未新增错误；同样修改在 +45° 跳变上救回 2 位、新增 20 错。连续频偏精化在两个离格频偏层分别净少 163、98 错，在两个跳变层分别净增 48、5 错。对应每层均为 11,200 位。两类配对使用不同的前端信息集，效应分别报告。

本目录以 [OFDM 固定提交](https://github.com/20171806011/EM-FloatFormer/commit/5f88a5be984493bcb6aa164d84253b6f29876eef) 为父版本。[A 的固定版本](https://github.com/20171806011/EM-FloatFormer/commit/f566f9b8b0ddfb468a4cb3fd64588bfa46c87212)和 [PLUTO 固定版本](https://github.com/20171806011/EM-FloatFormer/commit/ade8333fb68126251a83e484b69b821b5d97bcea) 各自保留。下列静态合成数据由代码生成。真实部分为原 435 MHz 录制的**历史逐帧表复算**。此次没有获得 IQ 二进制或匹配的学习权重，因此没有新的实测推理和独立录制确认。

## A/B 先决校验及单目标配对

两组交换同一输入、候选、方差、局部边际、转移和位映射。整数参考覆盖 21 个观测样例、49,280 个联合状态赋值及 156 个位，逐项比对 312 个候选×位。共用的复数 2×3 输入在 τ=1、6 两次核对 152 个标量，包含门权、有效权、分支内位概率与输出。τ=1 时原始读出、仅减显式项、严格重估依次为 0011、1111、0011；τ=6 为 0011、0011、0011，而完整权重乘归一化分支为 0111。温度 6 来自历史 Dev，将其作为经验温度。严格重估改变有效方差和其他格点的得分；固定量的等价式不能强制这两种重估给出同一输出。[合并校验与按层明细](experiments/parity/REPORT.md)

同一组 12 个母帧各派生热噪声、局部脉冲两层，各层 288 bit，共 576 个配对 bit 实例。[四个位序的 BER、NLL、救回和新增](experiments/parity/by_bit.json)可用 `node experiments/parity/by_bit.cjs --per-target` 展开为逐帧逐位损失。实跑的是 Skulpt 1.3.0 中的 Python。独立概率域枚举还核对 3,480 个位输出和 6,960 个候选×位。NLL 为温标校准前的自然对数损失，耗时为各方法处理相同目标的累计秒数。

## E 全帧门与最佳固定接收机

在全新的六枚拟合种子、两枚选择种子上固定四格门；独立检验再用另外两枚种子，各派生七层。静态容差预设为零。开发集选出的全局固定接收机为连续头；检验 14 帧、78,400 位中，离散／连续／门分别错 12,650／12,527／12,699 位，BER 为 16.1352%／15.9783%／16.1977%。门开 5/14 帧，相对固定连续头救回 1,480、引入 1,652 错，净增 172 错。整帧门没有在这批检验帧上胜过任一固定法。[七层 NLL、翻转、救回、新增和计时](experiments/whole_frame_gate/REPORT.md)

静态层两帧全开，门和连续头均 232/11,200 错，离散头为 248/11,200。四个连续频偏层合计连续头 7,455/44,800 错，门 7,726/44,800 错；+45° 跳变层门较连续头少 99 错，+90° 层两者逐位相同。三臂单帧端到端中位数依次为离散 577.5、连续 1,566.5、门 610.5 ms。此处以合成静态层占用 E 接口的 `C0_raw_ota` 键，实际 OTA 的非劣性仍待独立采集。E 的开发锁预提交 SHA-256 为 `43c82e49772b98f1cd000994beffdb51d62cd570736ab4d447a8e62931bea9c4`。原始 E 引擎从压缩位流重建同一开发锁，复现整个检验评分。[锁与证据摘要](experiments/whole_frame_gate/manifest.json)

## 重跑与文件校验

命令从本目录执行，Node 18+。所有文件使用 LF。[执行记录](validation.json)列出各脚本已运行的核验与环境。[冻结协议](PROTOCOL.md)给出汇合顺序、数据划分、注入与计分规则。下列 Python 独立校验只需 Python 3 标准库。原生 IQ 桥接另需相应固定源码、PyTorch、NumPy、SciPy 和授权本地数据。

```sh
node verify_bundle.cjs
node experiments/physical_layers.cjs > physical-rerun.json
node experiments/cfo/paired_cfo.cjs > cfo-rerun.json
(cd experiments/whole_frame_gate && node verify_vectors.cjs . ../../E new-vector-work)
(cd experiments/parity && python3 parity.py --a-reference ../../A/reference.json --out reproduced)
node experiments/parity/oracle.cjs experiments/parity/fixture.json experiments/parity/raw.json.gz.b64 A/reference.json A/ab_fixture.json
```

历史归档复核读取 Git 对象原始 LF 字节。普通工作树的旧文件可能按仓库根属性转换为 CRLF。以下从同一仓库中的固定对象构建临时输入。

```sh
pin=5f88a5be984493bcb6aa164d84253b6f29876eef
tmp_results=$(mktemp -d)
for f in group_b_per_tti.csv group_c_per_tti.csv group_b_results.json group_c_results.json; do
  git show "$pin:research/realdata_ofdm_stress_and_theory/results/$f" > "$tmp_results/$f" || exit 1
done
node experiments/historical/historical_pairs.cjs "$tmp_results" > historical-rerun.json
```

在具备相应依赖和授权 IQ 时，先执行 Dev 单帧校验。OFDM_DIR 指向固定提交 `research/realdata_ofdm_stress_and_theory/` 的 LF 源文件目录，IQ 指向本地已授权的固定文件。不可将原始采集、发送标签或模型权重加入此包。C 的原生匹配合成及桥接接口见 [C/README.md](C/README.md)，其中独立目录 `research/em-floatformer-c/` 在本包中对应 `C/`。

```sh
python3 experiments/paired_replay.py --ofdm "$OFDM_DIR" --dataset "$IQ" --scope smoke
python3 experiments/historical/real_smoke.py --source "$OFDM_DIR" --audit-dir B --pth "$IQ"
PYTHONPATH="$OFDM_DIR" python3 C/smoke_native.py
```

单帧输出对齐后，历史原 B 六法五条件回归可在第二条命令中加 `--b240`。冻结物理三层的原始/显式配对用 `--scope history-pair`，严格逐目标全量用 `--scope history-strict`（每一目标都重新估计，计算量高）。上述回放接口输出配对汇总；当前仓库的实证限于本页明确标注的已运行项目。
