# 合成 OFDM 的连续频偏单变量对照

在 17 路候选的 HMM 权重、噪声和位解调完全相同的条件下，只把前 9 个候选的离散斜率换成连续精化，两个离格场景在各 11,200 bit 上净少 163 和 98 个错误。两种跳变场景的错误分别净增 48 和 5。两枚测试种子足以构造和复现这些配对结果，尚不足以估计 OTA 总体收益。

## 冻结设置

2026-11-22 19:23:56 UTC 固定七种工况、种子、阈值、目标掩码、判决与计时口径；19:24:21 UTC 另固定 Dev 参照与 NLL 统计。两次记录均早于计分。使用独立单帧预热种子 55000。14 帧开发样本共 78,400 bit，在 D/C 中事先选取固定参照；再对另 14 帧同规模检验集评分。七层共用每枚种子的载荷与噪声，每层内部按相同帧和相同 bit 配对。重复工况不能当独立随机样本。零基行 2 为导频行，活跃列奇偶交叉拟合，各折目标在估计、HMM 权重和门控中均不可见。原型的导频 LS 和保护带估噪供三臂共同使用，历史信道分支退化为 LS。此处采用合成静态平坦信道和 AWGN，保留完整 16-QAM 映射、17 分支 HMM（τ=6，stay=0.8）、两折解调；没有调用已训练注意力头和实测 OTA。

D = 固定离散相位头。C = 实际任务 C 原型在各候选区间内精化，逐候选输出残差相位，其余输入相同。G = 在 D/C 间应用预设的支持集似然增益门，分折选择大于 0.5 log(n) 时启用 C。这一解析开关单独测试门控效果。E 任务涉及规则选择和风险证书，本项结果不计为该方法的实验。跳变是单独的输入压力层，发送机仅在行 7 起转相，接收机不读取跳变条件、角度和真值。

全局 Dev 参照选 C，D/C 错误数为 12,173/11,646，分母 78,400 bit。故表中 C→G 同时给出了 G 相对全局固定参照的配对代价。合成静态上，G 比全局参照 C 多 1 错（救回 1、新增 2），比本层 Dev 参照 D 少 3 错（救回 4、新增 1）。两种离格斜率的四折都启用连续精化，G 与 C 相同。时域 CFO 加 ICI 有两折回退，G 较 C 多 4 错。+45° 跳变上的开关净救回 68 bit。−0.313 场景硬判错误减少而 NLL 上升，硬判与概率损失应分别检视。

+45° 分层的跳前/跳后分母分别为 5,544/5,656 bit，跳前 D/C/G 错误数 56/87/88，跳后为 2,280/2,297/2,228。+90° 相应为 56/55/55 和 2,828/2,834/2,834。D 任务的理论下界使用不同的理想模型和角度/跳点先验，无法把此两枚固定角度样本均值当作该下界的估计。离格正负两层中，最佳连续斜率分别在 [0.22151, 0.22854] 与 [−0.31741, −0.31161] rad/行；即使全局最佳斜率接近注入真值，本试验仍按固定 HMM 权重混合各候选，不能由单轨迹的拟合精度推得零 BER。
