# 汇合实验冻结口径

固定 OFDM 接收机为 `5f88a5be984493bcb6aa164d84253b6f29876eef`，A 的原始理论参考为 `f566f9b8b0ddfb468a4cb3fd64588bfa46c87212`，PLUTO 为 `ade8333fb68126251a83e484b69b821b5d97bcea`。合并包在 OFDM 固定提交上新增独立子目录。这三个版本不互相替代。各小节标明独立合成、真实 IQ、新推理、既有 CSV 重算或数学证明。

1. **A 与 B 对齐。** 对相同观测、候选、局部密度、方差和位标签，用 A 的直接联合枚举逐候选和逐位核验 Python 的物理解调。原读出使用含目标的平滑权重并乘目标原始似然；显式删除只在目标行减局部对数边际，冻结所有其他拟合量；严格重建同时重算依赖目标的基线方差、局部有效方差、其他 RE 的行分数和特征，最后才用原始目标解调。温度 1 检查贝叶斯恒等式；历史 Dev 选定的温度 6、stay=0.8 用作经验对照。若出现差异，先检查有效分支权重、分支内概率与预测输入，不能换样本来消除差异。
2. **单变量频偏试验。** 预先确定取样条件、种子、正确位映射，离散与连续方法共享支持集、目标折、导频、信道、方差、门控和解调器，只变更相位轨迹的离格拟合。另固定相位头后改变门控。未提供学习权重或无法在同后端同输入上运行时，不以其他模型或随机初始化代替。
3. **分层和配对分母。** 原始录制 C0、连续频偏注入和相位跳变分列；静态合成与原始 OTA 分列。每种方法用相同帧、目标和 bit 标签。以自然对数、bit1 为正的 LLR L 计算每位 NLL：log(1+exp(−(2b−1)L))，以稳定的 softplus 求值。每位单独计算后再聚合。原始 LLR 与温标后 LLR 分列并标记使用的 Dev 温标。硬判 L>0。基准错而新方法对是救回，基准对而新方法错是新增错误；翻转=两者之和，净减错=救回−新增。缺少逐位配对资料时只报告可识别的净值/界，不能由 BER 差值补造翻转。记录分子与分母、相同计时边界、运行时及硬件可访问范围。既有汇总耗时不能用来替代本次同口径测量。
4. **跳变和门控。** D 的理想旋转模型按给定/未知跳点、额外导频分别评估。已知真相位、真工况或跳点的 oracle 只作界。E 的门控对比预先选好的最佳固定方法；必须单列静态/原始代价与动态收益。相位、门控、温度、评价口径不得在同一个单变量比较中一起改变。
5. **真实实验资格。** 原分割训练索引 0–339，Dev 360–481，两段 20 帧间隔，历史 Test 502–741。历史 Dev 设定锁定，原训练参考只读训练导频。条件和设定在评估前冻结，不用历史 Test 重新选头、温度、阈值或收缩系数。只有数据完整性、加载权限、依赖、修正校验、可用权重及原始输入定义满足相应实验时才运行该行；单帧 smoke 先于批量。两条 435 MHz OFDM 路径共用同一录制；原录制与其压力注入、不同方法或种子均不是独立采集或新的盲测。独立录制另行确认。此次包不分发原始采集和权重。
