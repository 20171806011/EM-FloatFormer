# 任务 C｜连续频偏能解释多少收益

集成包新增受控 2×2 合成消融、目标隔离入口和原生 smoke。运行说明与 17 路结果见 README.md 和 ablation.json。下文的单轨迹自检保留原来的条件与记录。

**结论。** 在单一逐行线性相位模型里，盲 16-QAM 的全帧似然已足以估计离格斜率，前提是导频锚定信道、观测行破除额外混叠、搜索区间先验足够窄。在两组无噪合成帧上，九点离散估计分别错 298 和 400 个比特，连续估计两组均为 0/5600。在一帧带真实 ICI 和 16 dB 加噪的自建信号上，错误由 163 降到 98。以上是机制检查。真实 OTA 的收益份额，以及普通头与平行传输头的差距，均待冻结回放测量。

## 2. 边际似然与混叠证明

令 d_s=s−s_p，A 为上述 16 点集合，X_sk 独立均匀，W_sk 独立服从 CN(0,v_sk)，其中 v 是复噪声的总方差。给定相对于外部相位基准的 h_k，Y_sk=h_k exp[j(φ₀+ω d_s)]X_sk+W_sk。对已知导频 x_p，其对数似然直接是 −log(πv)−|y−h exp(jφ₀)x_p|²/v。单一导频行在 d_s=0，只确定复乘积 h_k exp(jφ₀)，不能单独识别 h_k 与 φ₀。原型按固定提交做导频除法和实虚线性插值，将 φ₀ 吸收到 H_k。无外部基准时另自由拟合逐行 H_s 会把任意斜率吸收掉。

条件于导频估计 H 和冻结的 v，目标为
\[
\ell(\omega)=\sum_{(s,k)\in E}\left[-\log(16\pi v_{sk})+
\operatorname{LSE}_{a\in A}\{-|y_{sk}-H_k a e^{j\omega d_s}|^2/v_{sk}\}\right].
\]
这是用全概率公式消去离散隐变量所得。令 z=y H* exp(−jωd_s)，距离展开为 |y|²+|H|²|a|²−2 Re(z a*)，I/Q 两个四电平和可以精确相乘。固定提交的经验 H、局部 v 或帧内相关项使它成为条件评分，不能把它宣称为实测网格的精确生成似然。

旋转 π/2 置换 A，故只要 Δω d_s∈(π/2)ℤ，每一行各自置换星座后似然完全相同。这个条件也是分布可辨识的必要条件（至少一个非零已知 H、有限噪声的有效 RE/行）。均匀归一化 16-QAM 有 E[X⁴]=−0.68，圆高斯的非共轭矩为零，所以 E[Y⁴]=−0.68 H⁴ exp(4jωd_s)。两个分布相等迫使 exp(4jΔωd_s)=1。取所有有效非零整数偏移的绝对值之最大公约数 g，Bézout 恒等式给出 Δω∈πℤ/(2g)。只有导频行时所有斜率等价。若相位截距也自由且无锚，应取有效行之间差值的 gcd，首行相位另有四重歧义。

全部行 g=1，一个半开基本区间为 [−π/4,π/4) rad/行。若只有偶数偏移，则基本区间长度缩至 π/4。偏移单位为归一化 CFO 时，ω=2πεL/N，g=1 对应周期 N/(4L)=0.238806，可取 [−0.119403,0.119403)。C2 的 |ω|=0.164443…0.361774，小幅超出离散库最大值 0.36，远在无别名区间内。此处“可辨识”指分布，不保证有限样本极大点正确。

反例取 ω′=ω+π/2，令每一行 x′=x exp(−jπd_s/2)。x′仍是同分布的均匀 16-QAM，导频不变，所有观测连同同一噪声实现均可完全相同。d_s=1 的 (−3−3j)/√10 变为 (−3+3j)/√10，自然比特 0000 变成 0011。盲似然相等并不保证比特可唯一恢复。

## 3. 频偏引起的 ICI

取有用段第 m 个样本，m_c=(N−1)/2。其相位为 ωd_s+2πε(m−m_c)/N。若 Z_s,l 是加扰前实测接收频点，代入单位化 DFT 得
\[
Y_{sk}=e^{j\omega d_s}\sum_l C_{k l}(\epsilon) Z_{sl}+W_{sk},\quad
C_{kl}=\frac1N\sum_{m=0}^{N-1}\exp\{j2\pi[(l-k+\epsilon)m-\epsilon m_c]/N\}.
\]
对角项为 sin(πε)/(N sin(πε/N))（ε=0 取极限 1），参考行的对角相位为零；其导频仍受邻频污染。非对角项混合其他频点，逐行反旋转只能去除前面的公共因子。以单位功率单音测总泄漏为 1−|C_kk|²，C2 范围两端为 0.2054% 与 0.9912%。这是等功率理想化尺度，不能直接作为选择性深衰落载波的 ICI/SIR。

在已知静态频选信道、白噪声理想化下，精确行密度要对未知整行符号向量求和，指数中是 ‖y−exp(jωd)C(ε)diag(H)x‖²/v，导频分量固定。通常不能拆成 101 个独立单点似然。按候选 ε 对完整 FFT 网格精确反旋、有用段重 FFT 是另一种物理基线，在可逆完整观测且噪声相应处理时能消除该注入。它改变观测处理，若用全网格补偿后再切留出列，目标信息还会扩散到拟合列，应另案设计遮罩。在含 ICI 的模型中 C(ε) 一般随 ε 改变，以上 CPE 混叠证明不能直接作为 ICI 模型的不可辨识定理。

## 4. 原型、计算量与冻结接口

运行 `node estimator.cjs` 可重现 `checks.json`。无依赖，输入 14×128 fftshifted 的复数对 [实,虚]，行和 FFT 索引从 0 起。接口也可由 Node 导入。

~~~js
const C = require('./estimator.cjs');
const f = C.fit(y, visiblePilots, fold, {hLS,hCA,nv});
const head = C.classicalHead(f, true, logWBeforeTarget);
const targetRows = C.demap(y, f.ctx, head); // {s, k: absoluteFFTIndex, llr[4]}
~~~

hLS/hCA 是 101 个复数对，nv 为 14×101，外部 logWBeforeTarget 是 14×17 按候选归一化的对数权重；传入者负责其目标前来源。按活动列序号 k (0…100，不是 FFT 索引) 的奇偶固定分为两折。第 f 折只在 k mod 2 ≠ f 的非导频行数据上取 E；行 2 的数据对斜率贡献为常数。各折都保留同一组可见导频。把两折目标 LLR 按 (s,FFT索引) 合并为原库的行优先顺序。

区间预先选 [−0.40,0.40] rad/行，含零及 C2 两端，接收机不读取条件名、帧种子或注入真值。以九个物理格点及相邻中点划分闭区间，各区间含本格点，含端点均匀取 9 点，再把全部粗局部峰（含端点）相邻区间黄金分割细化，至宽 10⁻⁷ 或 30 次迭代。缓存评分并保留原格点和端点；有效搜索频率不是固定细格。每格得局部估计 ω_r，全局最佳给出单轨迹点估计。有限粗采样不会证明找遍所有极窄峰。每次评分 O(16M)，精确 PAM 分解为 O(8M)，M 为该折拟合 RE 数；总 O(Q·8M)，内存 O(M+Q)，Q 是实际不同评分数，由 fit.evaluations 返回。共享 17 路解调 O(17·16·T)，T 为目标 RE 数。fitDiscrete 仅评九点。正式 D 若已有冻结权重可直接用静态候选，无需跑连续搜索。

在 17 路接口中，D 和 C 共用外部权重。D 输出零相位残差，C 对 r=0…8 输出 δφ_sr=(ω_r−Ω_r)d_s，跳相和历史分支输出零，二者 log 方差刻度皆为零。连续残差不超过 11×0.045=0.495 rad，低于学习头 π/4 约束。无外部权重时，原型仅做单轨迹诊断，D/C 分别在九个格点/九个细化解中选得分最高一项，以 one-hot 解调。独立运行时用导频复数 LS 并按固定远端保护频点估噪带数值下限；这一简化前端用于自检。正式匹配须传同一份目标前 H_ls、H_ca、nv 和特征。JS 后端按原库的统一方差及自然比特定义写成 float64 参考。正式比较四组须共用同一个原库 compact 函数。随附 native_bridge.py 已把四组接至该函数：将固定提交的 research/realdata_ofdm_stress_and_theory 加入 PYTHONPATH，调用 receive(y, visiblePilots, [fold0_ctx,fold1_ctx], method)；method 可为 'discrete'、'continuous' 或冻结的 CPU eval-mode 学习头。ctx 字段在函数注释中，learned 路另需折内 cplx/scal。桥接参考实现利用 Node 子进程交换 JSON，不适合计时比较，正式性能测量应使用常驻工作进程或同运行时实现，另外记录真正端到端开销。

目标前规则涵盖信道、权重、相位和方差。原缓存的本行似然、跨行 HMM、全帧特征、3×3 NBI 能量、导频行数据噪声估计及信号功率上限都可能依赖目标 y。不能只从评分中删去一个 RE 后继续用原缓存。四组应按同一数据支持掩码重算上述统计（邻域平均按实际可见数归一化，空邻域退回同一基准方差），或输入已证明独立于本折目标的外部结果；保留冻结的 train-only 参考库。冻结前对整折目标任意替换，验证四组参数输出与目标前干扰统计均不变。解调时只把该目标 y 用入其符号条件似然。这里“目标前”是相对目标似然的证据留出，接收整帧后可同时使用前后行；它不等同在线时序因果。

对固定输入，后端对每个 x 累加 logw_sr − |y−H_r exp(jδφ_sr)x|²/v′，对 r 做 logsumexp，再按比特取两组 logsumexp 之差（1 相对 0）。v′ 按每行 log 刻度夹至 [−1,2] 后取指数乘 nv，下限 10⁻⁸；v′ 跨 r 相同，公共归一常数相消。条件于外部权重是精确的混合解调，连续极大似然点估计忽略峰宽，不是积分过所有 ω 的完整贝叶斯后验。

## 5. 四组冻结回放设计

| 组 | 目标前输入与输出 | 主要比较 |
|---|---|---|
| D 离散物理 | 同一掩码所算的 HMM 权重，17 路原物理候选，δφ=0，lognv=0 | 提供固定参考 |
| C 连续非神经 | D 的相同权重/方差，只对九个静态或斜率候选做有界似然精化 | D−C 仅改相位分辨率 |
| B 普通学习头 | 同一份 4 复数+10 标量特征和 HMM 权重。用冻结 MatchedRealTransformer 生成 (logw,δφ,lognv) | C 与 B 比较经典斜率与完整学习输出 |
| A 平行传输头 | 与 B 逐字节相同输入，冻结 PhysParallelTransportNet，输出相同三元组 | B−A 衡量两种头的配对差异；涉及结构及读出差异 |

全部使用相同网格、导频、位映射、冻结参考库、目标折、温度及解调后端。精化头直接读支持 RE 而学习头读其汇总特征；同源观测预算不等价于相同统计量。冻结前核验模型 checkpoint 与掩码协议，记录架构、参数量、种子、数值精度及文件哈希；若借用旧全行训练权重，仅能称固定留出输入上的迁移评估。预注册相位单项消融：对两学习头只取 δφ，强制使用 D 的 logw、lognv=0，可检查排名是否主要来自权重或校准。若需专门归因平行传输算子，进一步在相同架构内设置传输相位为零；A−B 本身没有隔离这一算子。

正式评价按原始 TTI 配对。主要报告 C2 BER (错误数/比特总数) 及 D−C、D−A、C−A、B−A 的绝对百分点；仅当 D−A 显著为正且远离零时给解释比例 (BER_D−BER_C)/(BER_D−BER_A)，附配对区间，不截断负值或 >1。不同失败机制可同时改变 BER，比例是按该基线定义的差额，并非机制的因果占比。补充 bit-NLL、注入斜率误差（仅作离线诊断，真实链路残余漂移会混入估计）、符号误差与各条件分层结果。采用原 TTI 为单位、保留时间相关的成块重采样，跨条件/复本/方法保持配对，块长及指标在 Dev 冻结。时间分别记共享前端、拟合/头、共同解调、端到端，报每帧中位数与 p95，保持相同硬件、线程、精度、预热、batch 与同步方法，含两折开销。任何对共享缓存的复用对四组一视同仁。

单导频插值偏差、深衰落/低 SNR 令似然平坦、范围外 CFO、跨行跳变或多普勒扩展、子载波相关相位以及有色 ICI 都可能破坏固定斜率解释。离格误差在 |d_s| 大时累积。例如斜率误差 0.04 在末行已是 0.44 rad。以上因素使收益大小必须通过封存回放测量。
