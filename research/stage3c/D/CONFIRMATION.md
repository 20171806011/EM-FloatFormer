# Additional independent test of the published decisions

The first C4 cache audit, using 4,194,304 independent mothers, suggested one difficult Q1 orbit. This motivated a separate confirmatory run. The fixed classifier is the already published s17 lookup at parent cbf3d2c0. For the follow-up, use exactly 2^24 new i.i.d. mothers, seed 967229, and no interim looks or refitting. Test whether *all* 96 chosen-versus-rival comparisons across two tasks and 16 orbits have positive population margins. Reject the union null only when every one-sided exact conditional binomial test rejects at .005; use the maximum component p-value. A single true component null suffices to bound the global false positive rate. No per-cell significance is claimed from selecting individual p-values. For a joint 95% claim that also includes stage-one intervals, assign at most .045 to stage one and .005 to this global test. The follow-up design is informed by the first audit; no portion of the follow-up simulation was used to fit the published classifier.
