# Stage 3C · Work F · 固定缓存的频偏符号干预

起点为 `bbc76e3813a24840b9821c59cb8047cb85652575`。实跑使用冻结 C4 模拟器和 s17 权重（SHA-256 见结果），Q3-repeat、无导频、2 dB、两个四比特索引、`h=ell=2`，布朗扩散系数 0.10 rad/√step，频偏为 ±0.35 rad/step。结论对应这个条件和这对频偏。

## 物理配对和读出干预

在物理世界 s，时刻 u 的相位为 φₛ(u)=s·0.35u+B(u)。两个世界复用符号、初始四相旋转、布朗创新和加性复噪声。独立脚本核对符号、漂移扣除后的相位差以及逐窗扣除信号后的噪声，相位与噪声比较采用绝对容差 2e-14。真实符号改变时重编码 W1、W2，并从各自含噪 W3 重算接收扇区。4,096 对中缓存改变 3,815 对，目标扇区改变 3,847 对。

令 Pₛₜ=Hₜ(zₛ)，其中 s 是真实频偏符号，t 是告诉读出器的符号。每个世界的两次读出共享同一 zₛ 和同一 yₛ。四格按 P₋₋、P₋₊、P₊₋、P₊₊ 保留，每格含四个扇区概率。逐样本损失差为 log[Pₛₛ(yₛ)/Pₛ,₋ₛ(yₛ)]。先在每个母样本内等权合并物理世界，再按种子在各自 16 个 64 样本块中有放回抽样。两物理世界与四次读出始终整块同行。

四格可展开为 Pₛₜ=μ+sW+tM+stI。四个基底 1、s、t、st 彼此正交且平方和为 4，所以每个系数是四格按对应基底加权求和再除以 4。脚本用这些系数逐样本重建四格，并报告 W、M、I 的平均平方范数。W 捕捉缓存随物理世界改变的效应，I 捕捉这种缓存改变对告知符号效应的调节。

参考表每个符号用 65,536 个校准母样本。依据四分之一转等变性合并计数，每扇区加 0.5，两个符号分别拟合。设 D=R₊−R₋、B=H₊−H₋。在 256 个缓存对上，权重取两符号经验质量的较小值再归一化（总重叠 0.962204）。最小化 ‖B−aD‖² 得 a=⟨B,D⟩/‖D‖²。再报告相对残差 ‖B−aD‖/‖D‖ 和加权 TV（‖B‖₁/2 的均值）。旋转核对将 W1 缓存索引加 4 模 16，W2 固定，比较四个概率是否对应循环移位。

直接逐样本求对数比，带符号参考在负、正世界的均值分别是 1.932433 和 1.987368。首个样本（种子 989011、索引 0）的缓存键是 [142,128]，标签是 [1,2]。负世界取扇区 1 得 log(0.72335992/0.01872596)≈3.653996，正世界取扇区 2 得 log(0.16940002/0.17545237)≈−0.035105。全量格子可以由复现命令导出的 NPZ 逐项检查。

固定偏置取 (0.4,0.3,0.2,0.1)。混合后的扇区 0 对任一竞争扇区的概率差至少为 0.92×0.10−0.08=0.012，所以 512 个缓存–告知符号组合以及所有样本四格逐条选同一答案。两种读出器的符号 TV 和损失差却不同。正交对照的相对残差为 0.482353，说明有幅度的符号响应也可能几乎没有物理对齐分量。

冻结脚本输出的 JSON 解析后与已存结果逐值相等。独立脚本直接取对数比、重建四格并复算七种控制，所有控制指标最大绝对差 4.45e-16 以内。校准种子为 988001–988008，测试种子为 989011、989023、989039、989063，共 4,096 对。Bootstrap 使用种子 989997 和 2,000 次重采样，区间以拟合好的参考表为条件，未计入参考表的校准不确定性。测试没有触发 1e-12 裁剪。

## 冻结宿主需要导出什么

对 256 个固定缓存对，每对分别告知 −0.35 和 +0.35，记录相同候选顺序下四个扇区的分数。确定性宿主需 512 次四候选评分。可保留原始候选分数用于审查，同时按固定评分规则和锁定温度导出归一化四概率，形状 `[2,256,4]`，索引依次是 `[-1,+1]`、`16*z1+z2`、扇区 `0..3`。若评分基于多个 token，记录候选序列和聚合规则。宿主与连接器、模型版本、模板及条件 ID、候选顺序保持固定。若符号同时出现在文本和相位向量中，两处一起改。随机宿主在每格重复评分。记录权重、模型、连接器、模板和评分配置的版本或哈希。模型输入只含允许的缓存及公开条件，标签只供离线打分。

使用冻结脚本的 `--host` 接口和 [原报告的 JSON 契约](../../F/F_signed_host_probe.md) 可计算同样的指标。宿主实验仍需回答其输出是否随符号变化、变化是否与参考方向一致，以及这种响应是否改善留出样本的 NLL。本次实跑的是 CPU 对照读出器。

## 复现

从仓库根目录运行（实跑 Python 3.12.14、NumPy 2.3.5）：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B research/stage3c/F/check_f.py --repo . --out /tmp/em_work_f_frozen.json
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B research/stage3c/work_results/F/verify_f.py --out /tmp/em_work_f_results.json --probabilities /tmp/em_work_f_probabilities.npz
```

NPZ 保留全部七种对照的四格概率，数组轴为种子、物理符号、告知符号、母样本、扇区。`cache` 与 `target` 的轴为种子、物理符号、母样本。使用 `numpy.load(..., allow_pickle=False)` 读取。
