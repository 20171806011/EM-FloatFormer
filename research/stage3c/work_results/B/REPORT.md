# Stage 3C Work B · 有符号频偏与布朗扩散

基线 `bbc76e3813a24840b9821c59cb8047cb85652575`。以下结论使用单条从零起步的公共布朗轨迹、恒定频偏、非负已标记时刻，以及固定的先验和观察协议。

## 联合律

以初始相位为基准，设 $U_j=e^{i(\omega t_j+\sigma W(t_j))}$，$m_j=e^{i\omega t_j}$，$v_j=\sigma^2t_j$。将角色按时间排序为 $1,\ldots,r$，令 $v_0=0,m_0=1$。第 $j$ 段的相对旋转具有确定性相量 $m_j\overline{m_{j-1}}$，乘上方差 $v_j-v_{j-1}$ 的独立中心高斯角对应的相量。逐段相乘生成整条轨迹，因此任意整数向量 $k$ 的矩为

$$
\mathbb E\!\left[\prod_{j=1}^r U_j^{k_j}\right]
=\prod_{j=1}^r m_j^{k_j}
\exp\!\left[-\frac12\sum_{j=1}^r(v_j-v_{j-1})\left(\sum_{a=j}^r k_a\right)^2\right].
$$

展开平方的协方差系数为 $\min(v_a,v_b)$。同一时刻可对应多个角色，零长度增量使它们共享潜相位。若 $\sigma=0$，各相量本身已确定整条轨迹。有限方差下，第一边缘矩 $m_j e^{-v_j/2}$ 分别由方向与模长恢复 $m_j$ 与 $v_j$，因此上述特征对**以初始相位为基准的潜旋转联合律**也是可辨识的。若把初始随机朝向乘进去，边缘一阶矩可能消失，不能照搬这个逆向证明。

把同一符号与初始朝向先验、AWGN、采集协议和固定 s17 编码施加于同一联合律，可得到相同的观测及目标联合分布，因而给出相同条件预测。仅 Q1 看两窗时只涉及 $h$。Q3 重发还需预测时刻 $T=h+\ell$，授权的同信道导频进入后需保留 $t_p$。新采集可共享潜相位并具有独立测量噪声。同编号复制只有一份证据。若不给有效导频，平衡独立均匀标签与随机公共四相朝向使 Q2 保持均匀。若 Q3 发独立均匀新符号，圆对称噪声下未来四个扇区条件概率各为 $1/4$。

## 遗漏信息的反例

- **只给终点角。** 令 $\sigma=0,\omega=\pi/2,T=4$，两套 $(h,t_p)$ 分别为 $(1,1)$ 与 $(2,2)$。终点未折叠角同为 $2pi$。固定两窗和导频的接收方位均为 $+1$，Q1/Q2 从 $(3,1)$ 变成 $(2,2)$。在固定时间 $(h,T,t_p)=(1,4,2)$ 时，$\omega=0$ 与 $\pi/2$ 的**折叠**终点仍相同，标签分别为 $(0,0)$ 与 $(3,2)$。第二个版本即使公开时间也成立。若公开未折叠角与非零 $T$，可直接恢复频偏。
- **只给各角色的确定性相量。** 令 $h=0,t_p=T,\sigma=0.2$，$(T,\omega)$ 为 $(2,0.05)$ 或 $(200,0.0005)$。三角色相角均为 $(0,0.1,0.1)$，未来方差却为 $0.08$ 或 $8$。在无噪两窗且第一窗收到 $+1$、导频尚未揭示的重发 Q3 中，扇区 0 概率分别是 0.991436 与 0.258204。若完整时间与扩散率已公开，接收者可以补回此缺失信息。这里的长时间是数学压力条件。

第一组用 s17 实际编码四个无噪声窗口，确认四个朝向各有不同码。每工况枚举 64 个均匀 $(x_1,x_2,G)$ 三元组，给定相同观测只留下一个。第二组独立积分圆上高斯密度的傅里叶展开。扇区中心为 $c$ 时，常数项为 $1/4$，第 $n$ 项为 ($2/\pi$e^{-vn^2/2}sin$npi/4$cos$n(c-mu)$/n)。取前 64 项，最小方差 0.08 下尾项绝对和小于 $10^{-74}$。与冻结版逐周期正态 CDF 算法比较，八个概率的最大绝对差为 $1.11	imes10^{-16}$。

## 已知与未知符号

令 $S$ 为独立均匀的公共符号，$\omega=S|\omega|$。已知符号时对该路径积分。隐藏符号时以 $p(Smid O)\propto p(Omid S)p(S)$ 混合两个条件预测，$O$ 为可见缓存及授权参考。每个时间点一律使用同一个 $S$。独立重抽会在两个非混叠的无噪时刻给不合法混合路径分配 $1/2$ 概率。对最优对数损失，平均收益为条件互信息 $I(A;Smid O)$。对最优准确率，收益来自最大值函数的凸性。某个观测下，若所有正后验权重的符号共用一个最优类别，则该处准确率无收益，即使概率不同。

1. 冻结脚本的受控例子给接收者真实初始**接收**朝向 $+1$，不揭示导频，$h=0,T=1,\sigma=0,\omega=pmpi/2$，未来测量 SNR 2 dB。用正交半平面投影计算扇区概率。已知与未知符号的最优准确率为 80.2765% 与 40.6793%，隐藏符号增加 0.506436 nats 对数损失。冻结 JSON 的全部数值逐项复现。
2. 无初始朝向提示的 CPU 补充检查复用冻结模拟器、s17 权重和每窗 4 比特的缓存对。原 C4 的 $+0.35$ 配上镜像 $-0.35$，$\sigma=0.10,h=\ell=2,t_p=4$，2 dB，Q3 重发且无导频。每个符号 32,768 条拟合、16,384 条留出；同一划分内两符号复用随机数，拟合与留出使用不同种子。沿用基种子 840101 与 840303，实际 RNG 种子为 84010103 与 84030303，只扩充区组数。观察量为两窗缓存，两个符号的留出各覆盖全部 256 种码对。每个符号的联合直方图加一平滑，隐藏符号时先合并联合计数再作条件归一化。留出准确率为 63.2355% 与 33.7128%，平均对数损失为 0.966528 与 1.309907 nats。这是拟合查表读出的留出分数。它与受控例子的时序、频偏、噪声和可见信息均有差异，因此分差不能单独归因于撤掉朝向提示。

## 正式实验接口

| 输入 | 两臂的设置 |
|---|---|
| 缓存、中文题面与候选、协议及参考 | 相同 s17 码对、题序、Q3 重发或新发规则、参考揭示时点、可见导频、共享信道标记及采集编号与去重规则 |
| 公开的物理元数据 | 相同角色与时刻 $0,h,T,t_p$、SNR、漂移族、扩散率，以及同精度的**有符号**频偏文字。累计方差可由共有时间和扩散率计算。工况命名在两臂保持一致 |
| 额外的数值槽 | 相位臂为相关角色的 ($\cos(\omega t_j),\sin(\omega t_j)$)，对照臂用同尺寸零槽。时间、扩散和参考的可用性保持相同 |

两臂共享训练波形、监督、预算及配对初始化。相量只由公开参数计算。在正式两臂中，符号已通过共有文字给定，所测的是数值表示的增益。隐藏符号的 CPU 对比回答的是符号信息本身的价值。宿主仍需在锁定的 $pm0.40$ 主工况和变时间条件检验能否使用数值槽、概率是否随符号正确移动，以及准确率和对数损失能否双双改善。Q2 还需检验宿主能否区分独立采集、复制和无关参考。
