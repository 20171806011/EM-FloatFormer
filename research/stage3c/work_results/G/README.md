# Stage 3C Work G · 一次代表元读出与群平均

冻结起点为 `bbc76e3813a24840b9821c59cb8047cb85652575`。本组核验四分类概率、缓存和模拟器，读出使用冻结查表及 Q2 数值核。宿主表现留待独立实验。

## 标签作用与一次读出

写两个缓存为 $z=4r+i, w=4s+j$。旋转 $g=(a,b)\in C_4^2$ 后，高两位分别加 $a,b$ 模 4，低两位 $i,j$ 不变。该干预将第一、二窗的发射符号分别加 $a,b$，并令重发窗的信号与噪声同转 $a$。导频、采集 ID、信道轨迹和公开元数据保持原值。在冻结模型中，均匀独立的发射标签和独立圆对称噪声使该变换保持联合律，连续漂移与固定 CFO 可以存在。

| 问题 | 标签 | 类别右移 $\chi_t(a,b)$ |
|---|---|---|
| Q1 | $X_2-X_1\bmod 4$ | $b-a$ |
| Q2 | 有效导频下的 $X_1$ | $a$ |
| Q3 | 重发 $X_1$ 后的接收扇区 | $a$ |

记 $T_d p[k]=p[(k-d)\bmod4]$。每轨道唯一代表元是 $(i,j)$。保持上下文 $c$ 原样，调用一次 $h(i,j,t,c)$，返回 $F(z,w,t,c)=T_{\chi_t(r,s)}h(i,j,t,c)$。旋转后右移量变成 $\chi_t(r,s)+\chi_t(a,b)$，由置换合成律直接得到 $F(gx)=T_{\chi_t(g)}F(x)$。反过来，任何等变读出都由其在代表元上的取值决定。联合律不变时，条件后验满足同一恒等式（对连续导频几乎处处），所以代表元参数化容纳该 Bayes 后验。训练可将标签逆移后交给代表元读出器。这里的保证针对四维概率向量。硬判决有并列最大值时，在代表元决定再移回，或对并列类均匀采样，才保持相应等变性。

冻结编码器的扇区选取为半开区间，并在窗和为零时改取第一个非零采样。全零窗在波形旋转下固定，带象限的码无法在该点满足自由的四相作用。冻结连续噪声模型中该点概率为零。数据符号干预也有别于接收机坐标旋转，后者会转动导频。任意实数角和带标签偏向的附加信息需要另行推导。

## 群平均的风险与单次上界

以下公式用 $x$ 表示含上下文的输入，固定一道题。记对齐概率 $f_g(x)=T_{-\chi_t(g)} f(gx)$，$P f=\frac1{16}\sum_g f_g$。换元 $g'=gh$ 得 $Pf(hx)=T_{\chi_t(h)}Pf(x)$。对概率向量凸且对同时重编号的标签和向量不变的损失 $L$，逐点 Jensen 给出 $L(Pf(x),y)\le\frac1{16}\sum_g L(f_g(x),y)$。若 $(X,Y)\overset{d}=(gX,Y+\chi_t(g))$，右侧取期望等于 $R(f)$。适当性用于解释 Bayes 后验，凸性与置换不变性给出不等式。定理也适用于对每个样本完整生成并均权评分的经验轨道。仅有输入边际不变不够，原始未配平子集也可能违背结论。例如只评分代表元且它原来给真类 .99、其余 15 处给 .01，平均后真类概率 .07125，NLL 增加。

Brier 的逐样本 Jensen 差是 $\frac1{16}\sum_g\|f_g-Pf\|^2$，所以在上述联合律下 $R(f)-R(Pf)=E\|f-Pf\|^2$。有限 NLL 的差则为 $E[\log(Pf)_Y-\frac1{16}\sum_g\log(f_g)_Y]$。严格改善当且仅当对齐后的真类概率以正概率不全相等。Brier 的严格改善对应任意概率分量的差异。

再固定一条轨道和上下文。条件于两者时 16 个位置等权且对齐后的真条件分布 $p$ 相同。令 $D$ 为 Brier 的平方距离或 NLL 的 $\mathrm{KL}(p\Vert q)$。群平均的超额风险不超过原模型的超额风险。单次代表元读出 $F_0$ 冻结选取原读出器在代表元处的整条预测，其超额风险 $D(p,f_0)$ 是轨道上 16 项非负散度之一。因此全局有

```text
0 ≤ R(Pf) − R* ≤ R(f) − R*
0 ≤ R(F₀) − R* ≤ 16 [R(f) − R*]
```

若只有代表元处输出偏离 Bayes 后验，倍数 16 可达。另一个直接比较来自 Brier 或 NLL 的连续性。令 `delta(x) = ||F₀(x) − Pf(x)||₁`，则 Brier 风险差绝对值至多 `2 E delta`。证明是逐类平方差因式分解，每项的两残差之和的绝对值至多 2。若两个模型在真类的概率均至少 `epsilon > 0`，对数的导数界给出 NLL 差绝对值至多 `E delta / epsilon`。系数上界需要这些条件，风险次序可由数据决定。

可复跑反例在对齐坐标使用确定真类 0。15 个位置给真类 .501，代表元给 .001，剩余概率给类 1。原读出、群平均和代表元读出的 top-1 准确率依次为 93.75%、0%、0%。Brier 依次为 0.591627、0.562330125、1.996002，NLL 依次为 1.079687、0.755555、6.907755。群平均可改善适当评分而降低 top-1，选用差代表元还会同时恶化两种适当评分。

## 读出调用数及宿主实验

| 情形 | 普通读出 | 16 路对齐平均 | 代表元读出 |
|---|---:|---:|---:|
| 单个缓存输入，一题一次请求，冷启动 | 1 | 16 | 1 |
| 固定题和所有上下文，覆盖全部缓存对 | 至多 256 | 至多 256 次原读出，余下离线 | 至多 16 |
| 每个母样本有不同的有效连续导频，同题、每母样本请求一次 | 至多 N | 至多 16N | 至多 N |
| 同样的 N 个连续导频，每个请求其全部 16 个旋转 | 至多 16N | 至多 16N 次原读出，余下离线 | 至多 N |

计数单位是独立输入评分，batch、候选串内部前向次数和墙钟开销另计。固定条件下 8,256 个母样本可用 256 行普通评分，将独立输入数降至逐母样本评分的 1/32.25 或更低。固定的是完整有效输入，包括 checkpoint、提示、候选顺序、精度、位置与导频/元数据。离线可将已枚举的原始候选概率按类对齐并平均，然后按母样本收集损失及配对置信区间。全精度导频改变了有效输入，除非证明充分统计量或以实测误差验证压缩，跨导频不能套用 256 或 16 的全局上界。离线评分仍需保留原标签、母样本和区块 ID。

后续宿主实验在同一冻结母样本上测未经包装的候选概率和自由文本，比较固定宿主原输出、离线群平均以及训练后的一次代表元读出。记录提示及候选字符串引入的旋转误差、NLL/Brier 与 top-1、连续导频参与下的配对效果，以及实测吞吐和提示变化对缓存命中的影响。
