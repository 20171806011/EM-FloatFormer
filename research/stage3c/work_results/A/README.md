# Work A · 迟到导频的 Q2 贝叶斯更新

基线提交为 `bbc76e3813a24840b9821c59cb8047cb85652575`。条件固定为 C4，SNR 2 dB，数据窗在 0 和 2，导频在 4。使用冻结 `equivariant_b8_s17` 权重和两枚 4 比特缓存索引。标签顺序对应 `[1,i,-1,-i]`。

## 从缓存索引到后验

令 $G$ 为初始载波的均匀四相旋转，$U=X_1+G$、$V=X_2+G$，均在模 4 下计算。由于两个发送标签和 $G$ 独立均匀，变换后 $(U,V,G)$ 仍联合均匀。公共漂移为 $\Phi_t=\omega t+\sigma W_t$，其中 $\omega=.35$、$\sigma=.10$。给定标签与相位路径，所有真实采样的接收噪声独立且为圆对称复高斯。

设 $F_z(\theta)$ 为表观相位 $\theta$ 产生缓存索引 $z$ 的概率，$b=\pi/2$。首窗发生在漂移零点，所以 $A_{z_1}(u)=F_{z_1}(bu)/\sum_j F_{z_1}(bj)$。第二窗先积分未知的均匀标签 $V$，得到 $m_{z_2}(v)=\frac14\sum_j F_{z_2}(bj+v)$。因此给定 $z_2$ 的导频相位分布为

$$
\eta_{z_2}(ds) \propto P(\Phi_4\in ds)\,\mathbb E[m_{z_2}(\Phi_2)\mid \Phi_4=s].
$$

由布朗协方差，$\Phi_4\sim N(1.4,.04)$，$\Phi_2\mid\Phi_4=s\sim N(s/2,.01)$。冻结核保存 $A$ 与 $\eta$ 的数值版本。首窗的噪声独立于路径和导频噪声，故其对 $U$ 的更新始终是 $A$。

对三点导频取匹配和 $T_j=\sum_n Y_{j,n}/\sqrt3$。给定 $(G=g,\Phi_4=s)$，$T_j$ 的均值为 $e^{i(bg+s)}$、复方差为 $1/\rho$，其中 $\rho=10^{.2}$。略去与 $(g,s)$ 无关的因子，写 $L_j(g,s)=\exp\{2\rho\,\mathrm{Re}[T_j e^{-i(bg+s)}]\}$。定义载波权重 $B_g$，归一化后有

$$
P(X_1=k\mid z_1,z_2,\text{参考})=
\frac{\sum_g A_{z_1}((k+g)\bmod4) B_g}{\sum_g B_g}.
$$

| 导频条件 | $B_g$ |
|---|---|
| 一次有效导频 | $\int L_1(g,s)\eta_{z_2}(ds)$ |
| 两次同一物理时刻的独立采样 | $\int L_1(g,s)L_2(g,s)\eta_{z_2}(ds)$ |
| 同一采样的副本 | $\int L_1(g,s)\eta_{z_2}(ds)$ |
| 只有一个独立无关参考 | $1$，故四类各为 $1/4$ |

采集编号标识随机观测。副本在已知原件后是确定的，同一编号只入账一次。独立无关参考对整组相关潜变量独立，其似然常数约掉，加入已有有效观测时也保持原后验。相位时刻标识路径上共享的随机变量。不同编号同在时刻 4 时，在同一个 $s$ 上先乘条件似然再积分。若真实时刻有别，就需要相应时刻上的联合路径分布。分别积分再相乘等价于为两次观测分别抽取独立的相位，差异来自给定 $g,z_2$ 的两项似然在共享相位下的协方差，归一化时只有对所有 $g$ 共同的比例才会消掉。

## 实跑和评测接口

从仓库根目录运行，环境为 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B research/stage3c/A/check_q2.py --repo . --export-kernel /tmp/stage3c-A-kernel.json > /tmp/stage3c-A-pinned-results.json
cmp research/stage3c/A/q2_s17_kernel.json /tmp/stage3c-A-kernel.json
cmp research/stage3c/A/q2_results.json /tmp/stage3c-A-pinned-results.json
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B research/stage3c/work_results/A/verify.py --repo . > /tmp/stage3c-work-a-results.json
cmp research/stage3c/work_results/A/results.json /tmp/stage3c-work-a-results.json
```

原脚本以种子 41117 校准 60,000 个提案窗，使用 20 阶桥接积分，以 920617 模拟 262,144 条母样本。原结果和导出的核均通过逐字节比较。独立代码读取冻结核、复用母样本种子做配对复算，并直接枚举 $U,G$ 与 20 个相位节点。它另外调用冻结宿主模拟器测试副本与无关参考的协议语义。此处使用同一批母样本检验实现与度量，采样标准误以母样本为单位、条件于固定校准核。

宿主评分可直接调用 `research.stage3c.work_results.A.verify.read_reference(kernel, z1, z2, records)`。核来自冻结的 `research/stage3c/A/q2_s17_kernel.json`。记录为 `(acquisition_id, same_channel, time, complex_matched_sum)`，同信道记录固定在时刻 4，SNR 为 2 dB。保留副本的编号，给独立采样分配新编号，无关参考传 `False`。以 argmax 计准确率、以真实标签的负自然对数计 NLL。此参考使用复匹配和。宿主若只收到量化后的导频特征，需要为量化观测单独建立似然；正交的宿主实验要回答模型能否在严格配对的输入上利用新测量，并对副本和无关参考保持同一后验。

## 核对结果

| 配对比较 | 准确率变化（百分点 ± SE） | NLL 变化（nats ± SE） |
|---|---:|---:|
| 加入独立第二次采样，沿用联合读出 | +8.5636 ± 0.0785 | −0.1683144 ± 0.0010732 |
| 一次采样固定，联合读出相对旧直读 | −0.0061 ± 0.0097 | −0.00003027 ± 0.00001571 |
| 两次采样固定，联合读出相对旧直读 | −0.0076 ± 0.0086 | −0.00004410 ± 0.00001797 |
| 一次采样固定，只启用第二窗相位更新 | −0.0084 ± 0.0095 | −0.00002383 ± 0.00001388 |
| 两次采样固定，只启用第二窗相位更新 | −0.0099 ± 0.0086 | −0.00003431 ± 0.00001575 |

联合读出的准确率由 64.6854% 升至 73.2491%，纠正 33,335 例，新增 10,886 例错误。第二窗的收益体现在很小的平均 NLL 变化上，准确率的差值约为一个配对标准误。严格的期望 NLL 改善由条件互信息决定。有限样本校准的差异与 Monte Carlo 标准误是两个问题。

独立复算与原结果的逐项最大差为 3.33e−16。全部 256 对缓存索引分别用一、两次采样各验一遍，共 512 个后验。与直接枚举、公开读出器相比，最大绝对差均为 5.55e−16。冻结宿主模拟器的 1,024 条 s3_test 母样本（种子 84030303）上，副本与单采样逐例相等，无关参考与无参考均严格输出均匀后验。

算例取索引 (3,12)，匹配和为 0.38−0.76i 和 1.21+0.44i。在同一相位节点上乘似然后积分，得到 `[.273438,.687455,.028424,.010683]`。分别积分后相乘得到 `[.273097,.690907,.026131,.009865]`，总变差为 0.003452。这对观测下 argmax 相同，概率质量已有可测差异。
