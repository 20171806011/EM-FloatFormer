# A 组独立复核：迟到导频下的 Q2

复核者先前负责 B 组，本次读取 A 组推导、校准脚本及发布读出器，在 CPU 上按默认规模重建校准表和评估结果。结论为**重现**。

## 复跑

从冻结提交的仓库根目录执行以下命令，仓库内含本次使用的基线源码及权重。

```sh
BASE=.
A_DIR=research/stage3c/A
out=$(mktemp -d)
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B "$A_DIR/check_q2.py" \
  --repo "$BASE" --export-kernel "$out/kernel.json" > "$out/results.json"
cmp "$out/kernel.json" "$A_DIR/q2_s17_kernel.json"
cmp "$out/results.json" "$A_DIR/q2_results.json"
```

权重 SHA-256 为 `e67d9fbafb90791ab19549de7789798d818286d7f52d7ac566cc39df71e78356`。60,000 条校准窗口、262,144 条测试母波形的完整运行退出码为 0，两个 JSON 均逐字节相同。两次真实采样相对一次采样的准确率提升 **8.5636 个百分点**（配对标准误 0.07846 个百分点），纠正 33,335 例，新增错误 10,886 例。两原子隐藏路径的枚举与分解计算最大偏差为 `5.55e-17`，公开读出器与向量计算在 512 次检查中最大偏差为 `1.67e-16`。

## 参考的概率假设

* **同一相位，两次新采样。** 两次测量共享初始载波和导频时刻的相位，条件于二者时测量噪声独立。因此应先逐相位相乘两个似然，再积分。另用发布表、缓存对 `(3,12)` 与导频匹配和 `0.38−0.76i`、`1.21+0.44i` 直接计算此乘积，与读出器的最大类别概率差为 `1.11e-16`。若改成分别积分后再乘（相当于重抽两条潜在相位），同一例最大概率差为 `0.00345180`。
* **副本。** 已知采集编号相同、测量值相同的副本由原观测完全确定，再条件化不会改变后验。独立调用读出器，追加相同编号的副本，输出逐项相等。
* **无关参考。** 当无关参考的生成机制与目标、已观测信息独立，且“无关”标记可靠，其似然因子在归一化时抵消。给单导频额外加入标记为无关的匹配和 `17i`，输出逐项相等。仅给该无关参考时，读出为四个 `0.25`，符合均匀初始载波的对称性。

该数值收益适用于 C4 的同一导频时刻、同一信噪比和指定生成分布。跨时刻的两个参考需对联合相位路径积分，不能直接沿用本表的“匹配和相加”规则。本次重现使用冻结的随机种子，报告的标准误以已拟合校准表为条件。
