# E 组独立复核：宿主样本量与功效

**结论**：原报告所列 129 个独立区组、8,256 条母波形以及两项正态近似功效可复现。以文中计划的 t 区间作最终判定时，若还要求每项的模型化边际功效均达到 95%，默认规划情形可取 **131 组，即 8,384 条母波形**。后一数字依赖正态区组均值等假设；波形与宿主的实测方差仍须在独立开发集估计。

在仓库的 `research/stage3c/E`（或本地工作目录 `stage3c/E`）运行以下命令。独立计算使用 SciPy 的非中心 t 分布，未调用原设计函数。

```sh
python design.py
python - <<'PY'
import json, subprocess
import numpy as np
from scipy.stats import norm, t, nct, binom
raw = subprocess.check_output(["python", "design.py"], text=True)
print("JSON matches:", json.loads(raw) == json.load(open("results.json")))
for q, rho, s in [(0.35, .01, .5), (.5, .03, .5), (.35, .01, 1.2)]:
    var = np.array([q, s*s]) * (1+63*rho)/64
    d, hw = np.array([.03,.04]), np.array([.02,.03])
    z = norm.isf(.025)
    bz = int(np.ceil(np.maximum(var*((z+norm.ppf(.95))/d)**2,var*(z/hw)**2).max()))
    def power(b):
        return nct.sf(t.isf(.025,b-1),b-1,d*np.sqrt(b/var))
    bt = next(b for b in range(32,5000) if np.all(power(b)>=.95)
              and np.all(t.isf(.025,b-1)*np.sqrt(var/b)<=hw))
    print(q,rho,s,bz,bt,power(129))
print(binom.cdf(2,129,.05), binom.cdf(3,129,.05), 1-.05**(1/129))
PY
```

独立单位是独立播种、各含 64 条母波形的区组。符号、旋转、两个模型臂与三套固定训练种子都在组内配对。129 组 × 64 母 × 2 符号 × 3 旋转 × 2 臂 = 每对连接层种子 **99,072** 个评分行；三对种子共 **297,216** 行。误差条对给定训练检查点成立。64 母均衡设计的组内协方差、种子间差异以及稀有大 NLL 对方差的影响均不能从评分行数反推。两个主要终点同时过线才判胜，各单侧水平 0.025 的交并检验无需因这两个必要条件再作 Bonferroni 校正；正态近似给出联合功效下界约 95.03%，对真实宿主只成立于输入的效应、方差和近似成立时。

独立地复核了可选的对称性哨兵。原假设失败率 5% 下，129 个独立哨兵至多 2 次、3 次失败的累积概率分别为 **0.04101、0.10917**。最多 2 次可通过单侧 5% 检验，零失败的 95% 精确上界为 **2.2955%**。此项有自己的终点与功效，未计入两项主收益的功效。以上为已执行的设计计算；没有从这些数值推断 Qwen 或 Ministral 的实测效果。
