# F 组交叉复核：固定缓存后的频偏符号干预

我核对了生成器与评分代码，并独立执行了完整 CPU 检查。两个物理世界使用相同的数据符号、初始相位、布朗运动创新及复噪声，分别代入频偏 −0.35 与 +0.35 rad/步，重新生成第二、三窗。改变真实频偏后，93.14% 的缓存对、93.92% 的第三窗观测扇区发生变化。因此评估“只改变告知符号”时，必须在同一物理世界内固定缓存及其真实标签。

复跑使用提交 cbf3d2c0 继承的生成器和冻结 s17 权重。下列等效命令从冻结提交的仓库根目录运行。

~~~sh
OPENBLAS_NUM_THREADS=1 python research/stage3c/F/check_f.py --repo . --out /tmp/stage3cf_independent_A.json
cmp research/stage3c/F/results.json /tmp/stage3cf_independent_A.json
sha256sum /tmp/stage3cf_independent_A.json
~~~

完整 JSON 逐字节一致，SHA-256 为 `5503fab1eabe5802f4250394e6c9c33e822ad660a8e86300f2e87bd904bd12d2`。另外，我绕开原有评分函数，按样本直接取同一个 `z,y` 在正确、相反符号表中的概率，重新求 `mean(log(p_correct / p_swapped))`。4,096 条新母波形各含一对物理世界，得到 **1.9599005402152403 nats**，匹配符号准确率为 **62.7686%**，交换符号后为 **3.6621%**。原程序按种子内 64 母波形块配对自助重采样的 95% 区间为 **[1.92194, 1.99955]**，条件于同一张校准表。

固定偏置分类器和“92% 固定偏置 + 8% 有符号参考”的分类器在 512 个缓存/告知符号组合上类别完全一致，匹配准确率均为 **24.5361%**。后者交换符号导致 NLL 增加 **0.145555 nats**，共支撑缓存上加权的符号总变差为 **0.054295**；前者两项均为零。该反例说明，即使所有硬判决都相同，概率也能沿物理方向响应符号。

这轮没有载入真实语言宿主的候选分布。以上结果验证的是诊断方法及其 CPU 对照；单凭历史正频偏准确率，不能判定 Ministral 忽略了频偏正负号。真实宿主需对 256 种同一缓存分别给出两个告知符号下的四候选概率，再用相同代码计算定向变化、残差及配对 NLL。
