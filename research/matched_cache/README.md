# 同预算下，四相信号的旋转关系能否保留到下一次提问？

**在冻结的 1,024 条合成测试母波形上，手工保相表示和带四相旋转约束的小型编码器均通过三项检查。普通小网络在 4、8 比特下都学到了有用的相位信息，但变换前后四个候选答案的概率不能逐项对齐。** 两种学习方法各训练三个种子。预先冻结的内容和发布顺序见[协议提交](https://github.com/20171806011/EM-FloatFormer/commit/9cc1b2516789a40c96d9bd204db40a58b50f61fb)。

## 怎样公平地问两次

第一问读取两个符号的相对相位，第二问在揭示参考后恢复第一符号。两道题、2 dB 信号模型、有效/独立/重复/缺省参考和母本划分均继承[上轮配对基准](../fourphase_paired_questions/README.md)。训练、开发、测试母本数分别为 4,096、256、1,024。每条测试母波形派生三个窗口版本，每个版本配四种参考。12,288 组记录中，同一母本的记录按配对样本处理。独立审计核对了输入样本及其全部四相旋转，训练、开发、测试间未发现复用。

每窗在 4 比特档取 4 种状态，在 8 比特档取 16 种状态。两个窗码拼进**同一个无符号整数**，分别只允许 16 或 256 种状态。Python 存储单元为一个字节，4 比特档的高四位恒为零。第二问可以访问缓存和新收到的导频。临时浮点激活、原波形、测试标签、母本编号和第一问的回答都没有进入第二问的接口。权重及概率表是整个数据集共享的静态参数。评分器使用每一参考条件声明的同信道状态和采样编号。

- **手工表示**将每窗的复数匹配滤波结果转入四相信号的正交坐标，对两个符号位的后验分别量化，查表读出各量化区间的解析条件概率。[推导](PHYSICAL.md)
- **普通学习编码器**从六个实数 I/Q 输入出发，用 16 个隐藏单元和可学习的有限码本选择窗码。训练时的教师信号是同一训练窗的无导频解析后验，模型推理只接收该窗的三点复采样。共训练 48 个 epoch，固定报告种子 17、29、43。[实现与训练设计](LEARNED.md)
- **带旋转约束的学习编码器**先把每个窗口转到统一象限，在象限内学习分区，读出时把概率转回。4 比特档每窗只有一个象限内状态，训练只校准读出的概率。8 比特档每窗每个象限有四种状态，学习的分区实际参与编码。

## 是否同时满足三项要求

判据对每个候选的概率取最大绝对偏差，容许数值误差为 $3\times10^{-13}$。每个方案还必须在两项有信息的任务上同时优于均匀猜测的准确率和对数损失，避免以恒定分布通过。下表中的“转动”和“保持”是对两题的全部相关检查取合取。所有方案均能在只转第二窗时保持第一符号的后验不变；普通网络失败的具体项目包括两窗同转时第一问的分布。

| 两窗总预算 | 表示 | 第一问准确率 | 有效参考后第二问准确率 | 第一问 / 第二问对数损失（nat） | 转动 / 保持 / 重复 |
|---:|---|---:|---:|---:|---|
| 4 比特 | 手工 | 69.73% | 69.34% | 0.9105 / 0.8453 | 通过 / 通过 / 通过 |
| 4 比特 | 普通学习 | 69.50% | 69.22% | 0.9140 / 0.8462 | 未通过 / 未通过 / 通过 |
| 4 比特 | 带旋转约束的学习 | 69.73% | 69.34% | 0.9108 / 0.8454 | 通过 / 通过 / 通过 |
| 8 比特 | 手工 | 70.12% | 68.95% | 0.7960 / 0.7858 | 通过 / 通过 / 通过 |
| 8 比特 | 普通学习 | 68.98% | 68.41% | 0.7809 / 0.7837 | 未通过 / 未通过 / 通过 |
| 8 比特 | 带旋转约束的学习 | 69.73% | 69.30% | 0.7833 / 0.7846 | 通过 / 通过 / 通过 |

表中学习方法是三次独立拟合所得指标的算术平均。每个种子的通过情况相同。普通模型在每档每个种子的全部 1,024 条母波形上都至少违反一项严格等式；这不等于在每条上都答错了标签。8 比特时，仅看“两窗同转，第一问分布应保持”，普通网络三个种子的平均总变差距离分别为 0.1282、0.0990、0.1006。

8 比特带旋转约束模型相对同预算手工模型的第一问正确率差为 −0.39 个百分点（按母本配对的点态 95% 区间 −1.27 至 +0.49），第二问为 +0.36 个百分点（−0.49 至 +1.20）。两问的对数损失差分别为 −0.0128（−0.0368 至 +0.0106）和 −0.0013（−0.0190 至 +0.0158）。区间针对这三个既定种子的平均表现。数据支持两者都能守住旋转关系，准确率的差异方向仍不确定。[完整比较与配对区间](results/summary.json)

## 看一条母波形的四项概率

测试母本 0、8 比特、种子 17，候选按 0°、90°、180°、270° 排列。下表显示带旋转约束的编码器在同一条波形上的输出（保留三位小数）。

| 条件 | 四个候选概率 |
|---|---|
| 第一问，原波形 | (0.054, 0.889, 0.054, 0.003) |
| 第一问，只转第二窗 90° | (0.003, 0.054, 0.889, 0.054) |
| 第一问，两窗同转 90° | (0.054, 0.889, 0.054, 0.003) |
| 第二问，揭示一次有效参考 | (0.029, 0.815, 0.151, 0.006) |
| 第二问，重复这次采样 | (0.029, 0.815, 0.151, 0.006) |

在同一母本上，普通编码器原本给相对角 90° 的概率为 0.903；两窗一起转后降至 0.732。它两次都选 90°。这给出了单看正确率会漏掉的失败样例。[普通模型逐项记录](results/test/plain_b8_s17.json) · [带约束模型逐项记录](results/test/equivariant_b8_s17.json)

## 哪些性质来自哪一层

旋转约束负责让概率排列与物理坐标对应。保留多少关于判决边界的信息由窗码的分区和读出表决定。参考身份由基准提供，相同采样编号的似然在公共读出器中只计一次。所有模型收到副本后，第二问概率逐项一致，最大置信度增量为零。把含噪值相同的副本故意重新编号为另一份独立证据，8 比特带旋转约束模型（种子 17）在原始波形上的平均总变差达到 0.07590。已知独立参考与没有参考都给出均匀分布，准确率为 25%。当前结果只覆盖该四相模型、该噪声水平及已声明参考来源。

在三个数据版本合计 3,072 个配对上，看 8 比特带约束模型（种子 17），无参考时统一用最小候选标签打破平局。有效参考纠正了 1,593 次、引入 234 次新错误，重复参考随后没有再改变答案。[独立核查结果](results/audit.json)

## 复现

使用 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0。在本目录运行下列命令。仓库提供全部 12 份训练权重，直接执行 compare.py 即可用它们复算。开发集和测试集都按方法、预算及种子存放逐项记录。

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python3 physical.py
python3 train.py --jobs 3 --output /tmp/qpsk-replay/weights
python3 compare.py --weights /tmp/qpsk-replay/weights --output /tmp/qpsk-replay/results
python3 audit.py
```

独立审计逐一枚举每种预算允许的全部缓存状态，对两个手工模型和 12 份权重用另一种求和顺序重建两道题的概率。与实验读出器比较，第一问和有效参考后第二问的最大差异分别为 $1.11\times 10^{-16}$ 和 $1.61\times 10^{-15}$。还检查了整数编码往返、母本划分、独立参考、同一采样的副本及故意错误编号的对照。
