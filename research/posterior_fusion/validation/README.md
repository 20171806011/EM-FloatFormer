# 可枚举的多分支接收机

在本目录运行。需要 Python 3.9 或以上及标准库。核算和计时分别写入，便于逐字节复核确定性输出。

```bash
sha256sum -c protocol.sha256
python validate.py --out reproduced.json --timing local_timings.json
cmp results.json reproduced.json
```

`protocol.json` 在验证程序首次执行前已固定。生成器采用 Python 的 `random.Random(seed).random()`。解码分数、联合概率、总体风险和边缘化采用有理数精确运算。训练权重取可观测校准对导出的有理数解，代码还实际计算其浮点点积 softmax，并核验二者在每个上下文的差小于 1e-14。复数协方差示例使用浮点复数并单列误差。训练和计时不使用网络或加速器。

## 共同数据和动作

每帧的二值分支 R 取 0、1 的概率为 3/5、2/5，分别对应实值标量信道 H=1、−2，嵌入复数 1×1 信道。Z 是已知导频的一位量化符号，以 7/10 概率等于 R。估计阶段仅见 Z。两个均匀独立的信息位产生偶校验码字 000、011、101、110。译码阶段额外看到 Y=(U,T1,T2,T3)。U 是块级幅度标签，以 21/25 概率等于 R。Tj 以 9/10 概率等于 Cj xor R。各观测噪声在给定分支、码字时独立。单个幅度标签的似然在每个分支、码字的乘积中只出现一次。

精确、硬选、物理近似、学习 attention 都使用相同码本、参数化分支信道值、逐分支目标似然、合法推理输入与评测分布。硬选接收机先计算精确的 P(R|Z) 并固定其中的 MAP 分支。物理近似故意把导频正确率设为 9/10，其他生成量均正确。这里可精确计算物理假设分布下的后验；将其代入真实分布才产生近似误差。精确方法作已知生成律的标尺。隐藏 R 仅进入数据生成和离线风险积分。

attention 在每个固定种子上单独拟合两个参数。离线训练仅含 1500 对可观测校准读数 (Z,V)，其中另一个已知导频的符号 V 以 91/100 概率等于 R。四种方法可访问相同的校准资料，前三种方法的固定公式无待拟合参数。推理不可访问 V。设 w=P(R=0|Z=z)，则模型预测 P(V=0|Z=z)=0.09+0.82w。每个 z 的二项边缘极大似然有闭式解，将经验频率反解并截取到 [0.001,0.999]，把结果的 logit 存入 k0[z]。k1=(0,0)，查询为 one-hot(z)，两项 softmax 实现所得权重。该小型可训练 attention 可饱和表示两个上下文的权重。未测试多层网络或跨分布学习。

译码时，按上下文权重对所有分支的“码字先验 × 目标似然”求和。逐信息位 MAP 计算 BER，整词 MAP 计算 BLER。同分时选零位或码表较早的词。评测是独立新帧分布的精确总体积分，包含 2×2×4×16=256 个原子，无测试采样方差。三个种子只改变校准集；所列学习风险条件于本次拟合。

| 方法 | 信道 MSE | 信息位 BER | BLER |
|---|---:|---:|---:|
| 精确软融合 | 1.8260869565 | 0.16560 | 0.25560 |
| 上下文 MAP 硬选 | 2.7000000000 | 0.34000 | 0.43000 |
| 物理模型软融合 | 2.1957824747 | 0.16752 | 0.25752 |
| attention，20261121 | 1.8310464412 | 0.16560 | 0.25560 |
| attention，20261122 | 1.8262173110 | 0.16560 | 0.25560 |
| attention，20261123 | 1.8265290213 | 0.16560 | 0.25560 |

给定 Z=0、1 的真实分支 0 权重分别为 7/9 和 9/23，Z=0 的概率为 27/50。每个策略的 MSE 超额精确等于 E[9(w−w*)²]。对硬选器，BER 与 BLER 的超额分别为 0.1744，具有严格次优块动作的观测质量为 0.2970016。逐位的对应观测质量对两信息位平均后也为 0.2970016。误码目标允许不精确的权重在全部这些有限观测上仍作出最优动作。

对统一截断码表 {000,011} 的附加核对，真实词遗漏率为 0.5，精确软策略在全分布上的 BLER 从 0.2556 升至 0.5828。各方法的详细差值、误码决策余量积分、两步分解与拟合参数保存在 `results.json`。

## 解析和复数核查

| 核查 | 结果 |
|---|---|
| 指定零噪声例，后验均值 plug-in | MSE 2.16，BER 0.60 |
| 同例，MAP 分支 plug-in | MSE 3.60，BER 0.40 |
| 同例，完整混合似然与同矩高斯似然 | BER 分别为 0 与 0.60 |
| 同例，交换先验顺序 | MSE 为 2.52 |
| 同例，错权 0.1/0.9 | MSE 为 4.41，超过硬选的 3.60 |
| 共同均值 4 | 两种估计风险均为 0 |
| 三个均值 −2、0、2，权重 1/4、1/2、1/4 | 唯一 MAP 分支取值 0，两种估计风险均为 2 |
| 权重与分支均值同时出错 | 估计偏差与直径上界均为 1.7 |
| 二维复向量、两个有内部噪声的分支 | 总协方差恒等式最大绝对残差 0；复数正交分解绝对残差约 8.9e−16 |

## 成本

每种方法为一个 (Z,Y) 的块决策比较 4 个合法词。软融合评估 8 个条件词似然，早期硬选评估 4 个，后者仍需先比较两个上下文分支。每个条件词似然包含一个幅度因子与三个符号因子。attention 训练每种子读取 1500 对观测，四个计数器，求两个参数，无梯度迭代。全体方法都可缓存这两个上下文的权重。描述性计时在同一 CPython 进程中，对同一循环观测次序每法重复 5 趟，每趟 1200 次；精确、硬选与物理近似使用缓存上下文表，attention 当场计算点积 softmax，均当场计算各自保留分支的目标似然。CPU、Python 版本、各趟时长及中位数见 `timings.json`。该计时仅描述本程序。目录中的验证与 P12 正式接收机实验相互独立。
