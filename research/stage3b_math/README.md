# Stage 3B 数学研究汇总：固定 8 比特缓存的最优读出

沿用 [Stage 3 提交](https://github.com/20171806011/EM-FloatFormer/tree/69fbd29acdb4eba7961d56176693786b6181477a/research/stage3_ministral_cache) 的四相模拟器、冻结的等变编码器和公开信道参数。研究对象是已经编码的两个窗口。每个缓存编号有 16 种取值，问题可以在编码后给出。仅在实验规定揭示导频的题目中使用该次观测。

## 数学结论

对给定问题和可用信息，最小化对数损失的读出是四类目标的条件分布，最小化判错率则选其中概率最大的答案。这里可计算的内容是怎样从量化缓存恢复这个条件分布。对每个可能的发射符号和连续相位，计算含噪窗口落入**实际编码器相应单元**的概率。沿两个数据窗、预测窗和导频共同经历的相位轨迹积分。这样可以在读取第二个缓存和新导频时，保留它们通过同一段相位演化产生的依赖。推导覆盖 Q1、Q2 和 Q3，学习编码器的数值积分与下列实测集中于无导频的 Q1 和重发协议 Q3。

已知频偏可以写成转角，但有限缓存一般不能被精确地转回去。实际权重下有两段输入都编码为 0，补偿 0.70 弧度后分别编码为 3 和 14。因此直接重排缓存编号不能实现这一任意角度补偿。已知频偏仍可进入各缓存单元的条件似然计算。该最优性结论以指定模拟器、固定编码器、已知参数和逐条波形决策为条件。学习编码器的概率表采用数值估计，未给出全局积分误差上界。

## 对同一编码器得到的两个结果

| 测试 | 样本 | 结果 |
|---|---:|---|
| Q1，两窗发射符号的相对相位，C4 已知频偏 | 131,072 条独立新模拟波形 | 原直读 50.2304%，按连续相位和缓存单元似然读出 60.6079%，提升 10.3775 个百分点，配对标准误 0.1406 个百分点 |
| Q3，第三窗重发第一符号，预测接收相位扇区 | 与上一行相同 | 两种直读均为 63.6215%，逐条决策一致 |
| Q3，单独改变读出使用的频偏，实际频偏 +0.35 rad/步 | 16,384 条新母波形；组内三个方法配对 | 正确符号 63.26%，忽略频偏 19.41%，反转符号 3.86%。正确使用相对忽略频偏提升 43.85 个百分点，配对区组 bootstrap 95% 区间 [42.64, 45.06] |
| Q3，重放上一轮宿主测试的原始母波形 | 128 条 | 正确符号 60.15625%，忽略频偏 19.53125%。历史 Ministral 及其连接层在这些母波形及其旋转变体上为 20.57% |

前两行使用两个独立积分种子拟合读出，两次都在同一套留出模拟上检验。频偏扫描的五个设置复用配对随机量，同一设置内校准种子与评估种子互斥。D 组的置信区间以指定读出及校准表为条件。频偏很小时，几种读出可以保持同一首选扇区，却给出质量不同的概率预测。准确率与对数损失需同时保留。

## 对宿主实验的决定

Q1 在进入语言宿主之前已有可挽回的读出损失，新的数值读出应作为同缓存参照。Q3 在此条件下，现有解析读出已实现与更细致的积分读出相同的判决。历史宿主的总体准确率接近忽略频偏的对照，这产生一个可检验的解释；要定位宿主内的机制，还需在同一波形上干预频偏信息并看逐条输出。

原训练条件的确定性频偏均为零。两个预测函数可以在所有训练角度上完全相同，在未见角度上给出相反答案。保留两种独立比较：

1. **零样本迁移**：冻结宿主与既有连接层，比较原始输入和已知物理规则可直接实施的变换，注明计算发生的位置。当前 C4 数值读出可作为解析参照。
2. **学习数值表征**：两个宿主、两种表示享有相同的非零频偏训练分布和预算，分别输入文字描述或由同一公开参数导出的正余弦；用独立种子与留出频偏检验。若以单元后验蒸馏读出，可将后验作为训练目标；把后验直接交给测试中的宿主则单列为语言转述对照。

## 可直接查询的概率表

[固定 C4 的概率表](A/c4_s17_lookup.json)与[查询及重建程序](A/c4_lookup.py)仅用于指定 s17 编码器、C4 条件和揭示导频之前的 Q1/Q3。输入任意一对 4 比特编号，即可取出两题各四个候选的概率。示例命令可在仓库根目录直接运行，只读取已发布 JSON，无需模型权重或第三方包。

```bash
python research/stage3b_math/A/c4_lookup.py read 3 12
```

表中按四分之一圈旋转对称性存入 16 个代表。覆盖全部 256 个缓存对的 512 个任务后验，与展开的数值积分表比对，首选答案零差异，概率的最大重建误差为 1.45×10⁻¹⁵ 以内。这是压缩表的重建误差，独立于蒙特卡洛积分误差。[GitHub Actions 复算与核验](https://github.com/20171806011/EM-FloatFormer/actions/runs/45816560308) 已完成。
