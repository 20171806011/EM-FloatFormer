# EM-FloatFormer 接入已有多模态模型的计划

**从项目现状算，三步得到首个可问答的接入原型，第四步在独立实测上验收，第五步检验同一模块能否换宿主。** 原长期计划中已有可辨识性、共享编码器和真实数据三项工作。共享编码器一旦能通过首批物理问题，就可以提前接语言模型。原计划后半段留给更长的波形、事件关系和开放式追问。[长期研究计划](LONG_TERM_RESEARCH_PLAN.md)

## 用户拿到什么

用户上传一段复基带 I/Q 录制，问两个时间窗之间有什么关系。系统把波形编码一次，保留一组与时间范围对应的连续向量。用户可以继续追问，也可以附上一小段新收到的已知参考信号。宿主模型的注意力能同时读取原波形向量、新参考和用户的文字。若同时给出一张标注时间窗的图片，还可以检验模型能否把图上的标记与信号中的证据对应起来。

首个宿主选 **Ministral 3 3B Instruct（BF16）**，正式研究依次加入 **Qwen3.5-4B、Qwen3.5-9B 和 Qwen3.8-27B**。Ministral 有开放的图文权重，语言主干支持连续输入向量。我们在宿主的输入序列中插入波形向量，并为各宿主分别训练小投影层。若计划部署到托管模型，原生接入取决于服务方是否开放自定义模态输入。[Ministral 官方权重](https://huggingface.co/mistralai/Ministral-3-3B-Instruct-2512-BF16) · [Transformers 语言主干接口](https://huggingface.co/docs/transformers/model_doc/ministral3)

## 五步与验收

| 步骤 | 做什么 | 怎样算达到这一步 |
|---|---|---|
| **1　用数学定下两次追问** | 从两个四相符号和一个未知公共旋转开始。第一问是相对相位，第二问是补充同一相干区间的已知导频后，第一个符号的原始相位。写清先后可见的信息、允许缓存的比特和噪声条件。再提出参考距离增大时可检验的预测。 | 用精确枚举得到各题在揭示前后的答案或后验。加入独立无关参考、重复同一观测、只保留相对相位三个对照。原计划中的 2 比特与 4 比特界仅用于无噪四相、固定长度、零误差的例子。 |
| **2　把波形变成可复用的输入** | 编码器接收 I、Q 采样和采样率等可用元数据，输出按时间排列的特征向量，每个向量都能对应回一段原始采样。同一波形的编码对不同问题共用。保存缓存预算、量化精度、时间映射和有效观测掩码。 | 先用简单的读出器检查，同一份冻结表示能回答相对相位，也能在补入有效参考后恢复原始相位。以完整 I/Q 和解析相量为参照。比较逐窗丢弃相位后，哪道题先失效。 |
| **3　与一个已有模型对齐** | 在提问中为每段波形预留位置，用小型可训练投影层把波形向量映射到宿主词向量的维数，连同文字进入注意力层。首轮冻结已验证的波形编码器和宿主，用波形、问题、答案三元组训练投影层。新一轮追加参考向量时复用原表示。 | 在未用于训练的合成波形上，模型能完成“先回答、再追问、补参考后更新”。平衡不同答案的出现频率，同一句问法配不同波形。只给文字、打乱波形配对或只保留幅度时，逐题核对预期变化。交付一个能实际对话的单宿主原型。 |
| **4　在真实波形上验收** | 用公开已知序列定义真值，优先选 Pluto 连续 QPSK 开发，在完整留出的 CTTC 会话或另一次物理采集上测试。在相同片段上对比解析读出、从冻结向量直接读出、宿主语言回答。加入时间轴图与 I/Q 共同决定答案的测试。 | 分别报告自然录制和人工相位干预。记录答案正确率、候选概率、补证前后改对和改错的样例，以及定位证据的时间误差。普通文本与图像问题也跑一组成对回归。若表示可被直接读对而语言回答错，先修对齐；若两者都错，用完整 I/Q 回查输入信息与相干假设。 |
| **5　迁移到第二个宿主** | 固定同一波形编码器、预处理、时间坐标、权重和问题集。为另一个模型训练专属的小投影层，用各自的对话模板组织上下文。 | 两个宿主都通过同一套物理干预与实测题，报告各自的误差、每段波形占用的上下文及推理开销。发布共享编码器、一份输入规范及各自的适配权重。结论明确限定在测试过的宿主和波形上。 |

## 第一版演示该长什么样

取四个相位标记为 1、i、−1、−i。无噪的两个接收符号是 i 与 −1，一开始只有两段波形。下表的数值供构造和评分，模型实际收到的是波形输入。

| 用户的操作 | 预期回答及物理依据 |
|---|---|
| “第二段相对第一段转了多少？” | +90°。两个接收值的比值为 i，共同旋转抵消。 |
| “那么第一段原来发的是哪个相位？” | 当前四个候选等可能。接收样点给出了旋转之后的相位。 |
| 补入同一相干区间的单位导频，导频接收值为 i，再问上一题 | 第一段的原始相位是 1。导频揭示公共旋转是 +90°，刚才的相对相位答案仍成立。 |
| 保持问题原文和两段输入的幅度，单独将第二段再旋转 +90° | 第一问的答案随波形变为 180°。若两段同时旋转同样的角度，第一问仍是 +90°。 |

这项演示只负责检验模态接入的第一种物理能力。随后才把问题扩展到“哪里发生变化”“两段是否仍能由同一相位轨迹解释”“图中的 A、B 哪段和参考相干”。设计图文与波形联合题时，可以让图片只提供 A、B 的时间位置，让波形提供相位关系。交换图中标记、单独改变波形，分别检验两种输入是否都被使用。

## 哪一部分值得投入研究时间

视觉模型 BLIP-2 已经展示了冻结宿主、训练小型连接器的技术路线，LEMMO 已经研究指令驱动的原始 I/Q 解读。我们可以直接借用成熟的接入思路。值得投入研究时间的，是测出**冻结的波形表示为后来的追问留下了什么、哪些证据能消除歧义、实际宿主有没有把这部分信息用起来**。第一轮的具体交付应是同一批波形上的解析答案、共享表示答案和宿主答案，三者之间的差距会指出下一步该改哪里。[BLIP-2，Proceedings of the 40th International Conference on Machine Learning，2023](https://proceedings.mlr.press/v202/li23q.html) · [LEMMO，arXiv:2611.09476](https://arxiv.org/abs/2611.09476) · [EM-FloatFormer D 组证明](https://github.com/20171806011/EM-FloatFormer/blob/e914befb2c03838c5e911e1af55c64230f1f42d6/research/abcde_convergence_2026_11_22/D/PROOF.md)

本文件为接入设计。实验范围和 Qwen3.8-27B 上限档位按用户选定，其余宿主与测试顺序为本轮建议。候选权重已经核对，实际接入、训练和实测验收仍待实施。
