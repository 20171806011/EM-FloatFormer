# EM-FloatFormer P3-B — exploratory, frozen protocol

**Freeze date:** 2026-11-15; **scope:** synthetic, receive-only, civilian QPSK/OFDM; no real radio hardware, active interference, radar, military data or transmit control. This is an extension of P3-A2, not a modification of any frozen P2/P3-A result. **This protocol is committed to GitHub before training or held-out evaluation.**

## Question and stopping rules

Can a small data-aware neural residual receiver provide benefits beyond matched-information classical receivers when a *single* physically modeled imperfection is introduced? Negative results and computational overhead must be reported. B0 physical checks must pass before training. Any changes to this protocol after seeing held-out results invalidate a confirmatory claim; **all P3-B comparisons are exploratory**, with no p-value-based model selection or universal RF superiority claim. P3-C/D/E are not part of this stage.

## B0 — clean link and physical implementation

- Exactly 32 frequency subcarriers, 16-sample cyclic prefix, one random known QPSK pilot OFDM symbol and one QPSK data OFDM symbol per frame. Unlike the P1 all-ones pilot, pilot is pseudorandom unit-amplitude QPSK and is revealed to all receivers. Data tones 0 and 8 are known QPSK anchors, their 4 bits excluded from BER: **60 evaluated bits per frame**. The same anchors are available to every neural or classical method for common-phase estimation.
- For each OFDM symbol: `ifft(X)` -> cyclic prefix -> optional memoryless baseband impairment -> linear causal finite-impulse response multipath (tap vector) -> circular-prefix removal -> `fft`; add independent circular Gaussian thermal noise in time with variance `N0/32` per sample, so frequency noise variance is `N0`. Pilot channel estimate is `FFT(rx_pilot)*conj(known_pilot)`. CP is longer than max 12-tap support. Separately model amplitude compression before channel, and noise/ADC/CPE after it.
- Verify no-impairment frequency observations equal `H*X` up to finite precision, thermal noise calibration, known pilot normalization, channel energy and CP convolution; under zero nonideality the old frequency-domain model distribution is recovered, **not** an identical legacy PRNG stream. Check waveform PAPR and clip power independently of BER.

## B1 — four independent, non-adversarial impairment axes

Never mix more than one additional impairment in a held-out test cell, with three severity levels: `clean`, `mild`, `strong`. A fifth, separately labeled *training-mixture* distribution may mix clean and individual mild axes across **batches**, never concurrently in one frame. All thresholds fixed below before testing.

| Axis | Mild | Strong | Position, effect and calibration |
| --- | --- | --- | --- |
| `pa` | Rapp p=2 magnitude knee `A=2.0/sqrt(32)` | `A=1.2/sqrt(32)` | Memoryless phase-preserving `x/(1+(abs(x)/A)^4)**(1/4)` applied to simulated transmitted pilot and payload time series before channel; record input/output power and EVM. No per-subcarrier clipping. |
| `impulse` | probability .03, independent Gaussian burst component of *mean* power .5 N0 | probability .05, mean power 3 N0 | Add independent Bernoulli-Gaussian **receiver noise in time** in addition to thermal noise. Report `noise_var` = total mean frequency-bin noise power to every receiver (not realized burst labels); log occurrence rate and sample power. No intentional emitter or jamming. |
| `cpe` | phi uniform [-.15,.15] rad | phi uniform [-.60,.60] rad | Rotate data-only received OFDM symbol by common phase, pilot unchanged; not equivalent to symbol-internal CFO/ICI. Both receiver families use the same two known data anchors. |
| `adc` | 8-bit per-real quantizer, symmetric clip `A=2.3/sqrt(32)` | 5-bit per-real quantizer, `A=1.3/sqrt(32)` | Clip/round received time-domain pilot and data including thermal noise, before FFT; no pre-quantizer gain change. Report saturation fraction, quantization distortion. Not full model FP16/BF16 execution. |

## B2 — fixed neural methods and classical references

- P3-A2 `D_no_pos_10` weights are **frozen**, five distinct checkpoints seeds 47101–47105; they remain the shared pilot-only physical backbone, mapped seed48101→47101 etc. It never accesses the true channel at inference. The D-only zero-shot baseline is evaluated on the same samples; report that it was trained using older all-ones full pilot but receives phase-normalized random pilots in P3-B.
- Train only a small **data-aware residual detection CNN** with 24 channels and three learned projections (1x1 stem, circular 3x1 convolution, 1x1 two-output head). Common channel estimates and phase alignment are computed by identical fixed functions for every encoding. Output residual added to a conventional QPSK equalized-logit skip; no channel-label, bit-label or true H at inference. Constrain total trainable parameters <5,000. `raw`, `log/phase`, `RMS-normalized IQ + log RMS` each use 3 equally sized features per complex observed quantity; these may differ in numeric conditioning and do not create information. All new models receive exactly the same pilot observation, payload, noise variance and two anchors. No additional attention, MoE, diffusion or P3-C half-precision kernels.
- **30 independently optimized heads:** 3 encodings × 2 training distributions × 5 new random seeds 48101–48105. Initial weights matched across representations and training distributions within each seed, same clean underlying batches and channel profiles. AdamW lr=.002, weight_decay=1e-4, gradient clip norm1, batch64, **600 steps per model**, BCEWithLogits on 30 unknown data symbols (60 bits); no early stopping or test-set tuning. Training SNR uniform 0..20dB, three profiles (`train3`, `equal4`, `long6`) mixed with equal weight. `clean` sees no impairments. `mixed` selects per *batch*: clean .40; each of four mild axes .15. Neither training mode contains 12-tap profiles.
- Classical controls from identical known pilot and anchors: LS, DFT-8 (max-delay-8 structural prior), DFT-12 (extended support prior), unchanged DFT hard threshold, LMMSE population prior built from **declared training profile mixture** (not test-profile oracle), and **decision-directed (DD)** DFT-threshold refinement using tentative hard QPSK decisions from observed data. Use exactly the same shared anchor-based phase alignment as neural models, and also report no-anchor DFT as a diagnostic. A correctly matched test-profile LMMSE and the true channel are **privileged diagnostics** only. There is **no demonstrated conventional PA-inverse/Bussgang receiver** in this first P3-B stage; for PA impairments do not claim neural superiority over all nonlinear-aware DSP. All methods see the same reported total noise power, not realized hidden noise events.

## B3 — frozen evaluation / statistics

- `train3`, `equal4`, `long6` evaluate in-profile; **`long12`,`sparse12`** remain disjoint out-of-profile. SNR **0, 10, 20 dB**. Conditions: clean + each of four axes mild/strong = **9 conditions**. Five new *train seeds* × 5 profiles × 3 SNR × 9 conditions, **768 held-out frames each**. Each method/condition/profile/SNR pools 5×768×60 = **230,400 bits**, except if a failed run is transparently marked incomplete. Use new independent evaluation RNG family disjoint from training and previous phases; share each sample batch across all methods; pair impaired and clean by underlying channel, bits and baseline thermal noise. No held-out result is used to alter hyperparameters, severity values or training budgets.
- Report every axis and severity; BER and `BER_impaired−BER_clean`, per-seed paired effects (seed is sampling unit), QPSK EVM on unknown bits, complex channel MSE and scale-aligned MSE (diagnostics only), observed impairment statistics, model parameters, memory and CPU median/p95 inference time plus separate pure synthetic link time. Show strongest nonprivileged classical method **per predeclared cell from the full fixed list** (a conservative, classical-favoring comparator); separately report D-only zero-shot and each of 6 trained heads. The exploratory *primary* report uses equal4/long6 at10dB under each of four **mild** axes for clean/mixed neural variants, and the best classical reference per cell; all other cells are descriptive stresses. No significance claim, p-hacking or post-test added seeds.

## B4 — integrity, release, limitations

- Pre-training: independently test FFT/CP/linear convolution, noise variance, pilot input nonleakage, clean-zero limit, distinct nonideal axes, PA shape/EVM, impulsive tails, CPE reference identifiability and ADC clipping; finite gradients and no true H/label leakage; all model configurations same shapes/initialization and paired minibatch streams.
- Save full per-seed integer error counts, frames/bits, paired RNG hashes, per-model SHA256, training logs, simulator settings, all latency recordings, and re-run at least one held-out cell per seed from saved weights without retraining. Verify result CSV independently and run suites. Stop without neural 'win' conclusion if baselines incomplete. P3-B does not prove actual radio performance, saturation recovery, universal channel optimality, real-world anti-jamming or full low-precision execution.
- Source and documentation go in the existing `20171806011/EM-FloatFormer` GitHub repo without modifying P2-E or P3-A/P3-A2 frozen report files. Model weights only in separate complete offline archive. Do not start P3-C without separate plan.
