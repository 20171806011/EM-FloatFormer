## 五、Codex CLI (`gpt-6.2-astra`, `ultra`) 数学验证与审视摘要

Codex CLI 在只读模式下对代码库、冻结哈希、全量 `3,840` 条正式记录及全部 `8` 项 `2^16 = 65,536` 符号翻转精确 Holm 检验进行了独立重算与机理审视，全部数字与判决均完全复现，核心数学诊断如下：

1. **Primary `full_reset = 20.00%` 的物理与几何成因（a）**：
   - 相比 `p11_payload_only`（`2,430/8,192 = 29.66%`）与 `9e9d93b`（`28.86%`），串联波前同化分别减少了 `792` 个错块（`+9.67 pp`）和 `+8.86 pp`，但仍高于 `dense/always_clear`（`667/8,192 = 8.14%`）和 `payload_only` 的每目标行共模相位神谕（`511/8,192 = 6.24%`）。
   - **关键拆解**：`84.31%`（`1,381/1,638`）的 `full_reset` 错块发生在 **Wave-1 解锁完全正确** 的折单元中；在 Wave-1 正确子集内，`Fold 0` 仍丢掉 `1,141/5,005 = 22.80%`，而 `Fold 1` 仅为 `240/2,515 = 9.54%`。在 `58` 个 `absent` 单元中也有 `54` 个位于 `Fold 0`。
   - **Fisher 信息与几何不对称性**：未知载荷的协方差似然 $C_r = H_r H_r^H + n_0 I$ 对整行共模相位 $H_r \mapsto e^{i\phi_r} H_r$ 完全不变，且对共模频偏的曲率中行中心时间相消，故 `5` 个 `AUX` 行无法提供帧级共模相位/多普勒锚定；一旦同化出正确码字，其相干局部信息矩阵在消除相位截距后的共模频率 Fisher 信息为 $J_{f\mid\phi} = 2(2\pi)^2\sum_n e_n(u_n - \bar u_e)^2$。在严格全折隔离下，`Fold 0`（承担 `11/16` 核心行）仅能使用锚点 `10` 之前的两个助手行 `(9,)`（Wave 1）和 `(0,)`（Wave 4），对应行中心时间杠杆平方和在 Wave 1 仅为 `1.125`（全接纳上限 `136.5`），使 `11..18` 号后半帧目标行落在所有相干参考之外；而 `Fold 1`（`5/16` 核心行）在 Wave 1 即由 `(9, 11)` 双侧夹住锚点 `10`（时间杠杆 `4.5`，全助手上限 `665.0`）。同时，由于 `AUX` 行已参与粗提议与 `160/5832` 联合节点压缩重采样，事后不可直接将其转正为虚拟导频，必须采用留一法重建提议。`full_reset` 校准比 `0.86x`（`3716.38 / 4327.77`）反映包含折间分歧项的预测方差偏保守，需以链式输出上的后验相位神谕进一步剥离剩余相位误差与分支选择误差。

2. **`continuous` 非劣性、净交付分解与 OOD 覆盖（b）**：
   - 配对集群 `df = 15` 统计量复核无误：$\bar d = -0.0854492\text{ pp}$，$s_d = 1.6136938\text{ pp}$，$U_{95} = +0.6217724\text{ pp} < +1.00\text{ pp}$（**支持**）。
   - `continuous` 净交付增益 `+122.375 bit/帧`（`+13.00%`，`16/16` 集群全胜）可精确拆分为：`+121.500 bit/帧` 来自将稠密导频行 `(0, 9)` 回收为有效载荷（`972/1024` 块成功），`+0.875 bit/帧` 来自 `16` 个核心目标行多成功 `7` 块（`7538` vs `7531`）。（注：`(0, 9)` 由 `Fold 0` 同化后再以最终状态重解码，严格未泄密目标解释适用于 `16` 个 `CORE_ROWS`。）
   - Primary OOD 机制 `ood_strong_shift`（`10.21%`）与 `ood_midframe_shift`（`11.11%`）同 ID `partial_shift`（`10.67%`）高度接近（差值 `-0.464 pp` 与 `+0.439 pp`），直接源自冻结 `144`-假设库对 `ONSET_ROWS=(0,6)` 与 `DELTAS_OOD` 的覆盖；`donor_mismatch`（`20.07%`）与 `full_reset`（`20.00%`）的 Fold0/Fold1 分布及校准比（`0.86x`）高度一致，通过合理性检查。

3. **Secondary 离格流形瓶颈与对照组解析（c）**：
   - **Global Transport vs Absolute**：在 ID 上稳定挽回 `82/18,432` 块（`+0.4449 pp`，`13/0/3`，`p_holm = 45/4096`，3 个种子各自均有正向增益 `+0.467 / +0.461 / +0.212 pp`），但该实现同时耦合了复内积相位对齐 $\operatorname{Re}(qk^*U)$ 与值向量旋转 $\bar U$。
   - **Global Transport vs Local**：ID 错块数为 `12,168` vs `12,169`（仅差 `1` 块，`p_holm = 1` 精确成立），OOD 为 `-29` 块（`-0.31 pp`）。源码确认 `em10_local` 自身已在每条径的相邻 `3` 个时间位置上执行了相同的有符号 $U(1)$ 相位搬运，因此该对比检验的是“全局跨径/长程感受野”的增量，而非“相位搬运本身”。
   - **No-History 对照边界**：`em10_no_history` 仍共享 Frame-A 发现的离散连续时延原子与先验功率，并在真实继承/清零分支上混合输出，其 `+11.90 pp` ID / `+7.40 pp` OOD 差距度量的是历史敏感门控特征的价值，而非纯 Frame-B 接收机基线。
   - **与 `oracle_true_channel`（`5.35%` ID / `11.91%` OOD）的 ~`61 pp` / `70 pp` 鸿沟**：Frame-A 的 `4` 导频梳状位置 `(-14.25, -0.75, +0.75, +14.25)` 在 $\Delta\nu = 1/14.55$ 处产生高达 `0.969815` 的时间导向矢量混叠（真实旁瓣峰值 `0.972981`）；Frame B 仅提供单行漫游锚点，且最终输出受限于固定两分支混合 $w\mu_{\rm inherit} + (1-w)\mu_{\rm clear}$，缺少基于 Frame-B 载荷重构与波前重拟合的闭环（`clean_nmse ~ 0.57` ID / `0.68` OOD）。

4. **P12 优先级建议**：(1) 对 `p11_chained_wavefront` 输出施加后验共模相位神谕以量化 `Fold 0` 剩余 `1,141` 个错块的相位误差占比；(2) 在固定导频预算下消除 `Fold 0` 后半帧助手真空（双侧平衡折划分或留一 `AUX` 重建）；(3) 评估真正落于冻结 `ONSET_ROWS` 支撑集之外的未建模起始行与多径移位；(4) 在扩展注意力之前，先用真值辅助混合诊断分离离格前端表示误差与门控误差，并开展正交 `2×2`（局部/全局 × 相位搬运/绝对值）消融。
