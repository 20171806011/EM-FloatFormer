# Phase 6 prospective confirmatory protocol

## Registration and primary outcome

The statistical unit is the regime–pair, including its independently initialized training run and paired test frames. The primary outcome is the total number of failed LDPC words for a receiver on the ten evaluation batches in that pair. Lower is better. Use the final checkpoint after the fixed 48th update for every receiver and regime. All inference uses the receiver's raw logits. A pair is never an independent observation twice within a test. The registered cohort sizes are fixed. No optional stopping, replacement of pairs, post-selection of checkpoints, pooling of arms or transfer of evaluation data into training is permitted. This is a single prospective evaluation. A negative contrast remains part of the results.

## Frozen receiver and fitting

The uniform recipe is fixed in [the development recipe](results/dev_math/final/recipe.json), with its numerical acceptance checks in [the development gate](results/dev_math/gate.json). The shared three-pass, width-eight axial waveform solver uses a centered initialized map, 856 trainable real scalars and 856 frozen initial-map scalars in each fitted arm. The five variants are Axial-Pure, Local-Pure, Axial-Parity, Local-Parity and Axial-NoGauge. Parity and NoGauge are explicit structural controls. Attention and Local receive the full identical grid and differ in their mixing operator. Both use the same physical readouts, capacity, initialization tensors, simulator draws and training objective. Fixed and Fixed+Parity run the same three-pass physical equations with zero learned handles. R1 retains the original PA and CPE readouts. R2 uses a coarse bank with inverse temperature 160. Its final pass mixes the bank residual (inverse temperature 40 + 120λ) with the local two-coordinate, ridge-damped chirp tangent using weights λ and 1−λ from the normalized pilot information matrix. The complete frozen runtime mode is fisher_trust. The development attenuation study shows a decoded-word cost on some severely damaged pilot grids. R3 uses the lag-steered array smoother. The colored-noise IRC alternative remains disabled. The training objective is BCE on 10 tanh(LLR/10) plus 0.005 CFR NMSE and 0.00005 squared displacement from initialization. Adam uses B4 from stream 5 with update indices 0–47, unit gradient clipping, four warm-up updates, peak LR 0.0045, then cosine decay to 0.00045. Initialization uses stream 5, batch index 900. The paired initialization and training draws are shared across all five variants.

## Inference

For decoded counts the paired improvement is comparator errors minus focal-arm errors. Report all ten numeric differences and W/T/L, ties excluded only from the exact two-sided binomial sign test. For m non-ties and k wins the raw p value is min(1, 2 × sum from i=0 to min(k,m−k) of C(m,i)/2^m). Return 1 for an all-tie comparison. At m=10 the smallest possible two-sided p is 2/1024. Apply Holm independently to each registered family at 0.05. Sort raw p values ascending, multiply by the number of remaining hypotheses, take a cumulative maximum and cap at one. Report raw and adjusted p, pooled effect and direction even when the effect favors the comparator. All formal hypothesis tests use cohort A. B is a descriptive benchmark and integer-reproduction check.

1. Three primary equal-information classical comparisons. Compare Axial-Parity against R1 Pilot-CPE-DD, R2 Waveform-DD and R3 Waveform-DD. Also report nominal IDD-PA and privileged Genie-PA for R1.
2. Three primary fixed-anchor comparisons. Compare Axial-Parity against Fixed+Parity in each regime.
3. Twelve structural comparisons in one Holm family. Within each regime compute Axial-Parity versus Local-Parity, Axial-Pure versus Local-Pure, Axial-Parity versus Axial-Pure, and Axial-Pure versus Axial-NoGauge.
4. Four structural Green comparisons for R3 Axial-Parity. Higher is better, so define improvement as focal coefficient minus reference. Test trained direct joint versus its shuffled null, trained direct joint versus the same pair's measured uniform-support control, trained versus initial historical product, and trained spatial axis-only versus the historical reference 0.084. The historical scalar is a contextual threshold with potentially different operator/support; it supplies no paired historical checkpoint. Report initial, trained and shuffled direct, historical and spatial metrics, plus Axial-Pure descriptives. The development uniform mean was 0.2687024. For prospective inference use the actual per-pair uniform correlations because the realized Green targets change with the pair.

Green targets are used only after inference. Score one eight-burst R3 probe on stream 8 for each A pair, with eight key permutations per layer from stream 9. The direct parallel joint averages support-restricted axis transports. The historical product composes them. Compute Pearson correlation on off-diagonal entries, average bursts and EM passes within each pair, then give equal weight to pairs. Spatial axis-only uses same-line entries. Report any undefined coefficient explicitly.

## Replay, symmetry, attribution and latency

Independent scoring processes reload checkpoints and repeat all ten B8 draws. Require exact SHA-256 equality for each waveform and codeword tensor, equality for every score-dictionary field including floating channel-error and reference energies, and equality of stored probe measurements. Retain per-field discrepancies. A technical retry may recover an interrupted write with identical frozen code and seeds. An observed numerical or scientific failure stays in the record.

For A, audit Axial-Parity and Axial-Pure for all ten intact, erasure, antipodal/tied-pilot and zero-noise conditions on a separate B2 stream-7 draw (index 950) for each regime and pair. Use the original 27-magnitude grid 1e-35, powers of two from 2^-12 through 2^12, and 1e20, with seeded per-burst rotations. Require finite outputs, zero flipped payload coded-bit decisions, max absolute LLR discrepancy <1e-12 and max relative CFR L2 discrepancy <1e-12. Report deviations without changing the frozen receiver. Run paired fixed-weight suppressions on the ten scored B8 frames for both parity arms over all A pairs. Report full, individual applicable handles, the R2 bank and all-handles-off controls; attribute causal effects only to these within-checkpoint interventions. These effects may interact.

Measure latency serially after project workers exit, with intra- and inter-op threads set to one, on the first A pair of each regime, B1 and B64, stream 7 indices 970 and 971. Warm up twice and time seven shuffled rounds per method, excluding simulation and final decoding. Record method samples, medians, quartiles, affinity and observed host load. Use six single-thread workers for formal fitting, with one fresh worker process per pair for primary scoring and replay. Record the exact environment with the manifest. Capture checkout and legacy verifiers again after evaluation. The freeze manifest locks the P6 source, this protocol, the selected development evidence, the protected commit and the content inventories of P5 and P5-B before formal access.
