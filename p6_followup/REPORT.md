# P6 后续数学优化：平滑符号图册与 R2 发射恒等化简

日期：2026-11-19。基准：[已发布 P6，63ad2ec](https://github.com/20171806011/EM-FloatFormer/commit/63ad2ec5b22027ea3d6f15aa50619a9caf6bbcd1)。

## 结论与状态

**本次有代码、有新波形实验、有同环境独立代理推理重放；没有重新训练，未通过 P6 的全部严格数值门槛。**
在两项预先固定的导频清零压力测试中，新 Smooth 相对冻结 Trust 分别减少 92 和 134 个错误码块，
Holm 校正 p 分别为 0.01953125、0.0078125。旧 Hard chart 在这两项中都比 Smooth 少错 2 块；
新方案不能宣称解码性能胜过旧 Hard chart。符号边界的一阶连续性是此次明确的数学变化。

完整导频和交错清零条件下，三种相位规则的汇总整数统计相同。严格复数缩放审计中，Smooth 在
一个弱导频条件出现约 2.10e-12 的 LLR 差，超过原有 <1e-12 门槛，虽未产生硬判决翻转。
因此作为**可选研究实现**发布，不替换 P6 默认接收机，不宣称新的正式阶段完成或模型全面胜出。
仓库历史文件、P4/P5/P5B/P6 代码与检查点全部保持原样。

## 1. 实际修改了什么

P6 的 R2 最后一遍将全局模板更新与局部切向更新按导频信息量 q 混合。q 很小时，局部更新可能
保留错误的多普勒方向。原先的硬符号 chart 能保留全局方向修正，却在两组分数相等时不连续。
本次先分别求正、负多普勒图册的条件均值，再用组分数质量差的平方门控：

\[
d=\tanh((\log Z_+-\log Z_-)/2),\quad
r_{weak}=(1-d^2)u+[d]_+^2(m_+-\theta)+[-d]_+^2(m_--\theta),
\]
\[
r_{new}=q r_{bank}+(1-q)r_{weak}.
\]

这三个权重非负、和为 1；符号证据相等时回到既有切向更新，明确时允许全局方向修正。
平方 ReLU 使 chart 切换项的值和一阶导数在边界消失。该结论仅涉及有限 logits 下的图册切换，
不意味着整个接收机全局 C1、Lipschitz、单调收敛或更低 BLER。分数置信度也不是校准后的贝叶斯后验。
q=1 时保留原有公式，但完整导频并不在所有可能信道实现上保证 q=1。

另外，R2 不含功放非线性，原发射步骤中的补零 IFFT 与 FFT/抽取在精确算术下复合为恒等映射。
可选 `exact_emit` 直接返回输入，省去每个 EM 步骤的一对变换；后续 Doppler/ICI 波形运算仍在。
浮点舍入顺序改变，故不保证逐位相同。**所有主要 BER/BLER 比较均禁用该可选化简**，避免混淆归因。
完整推导与导数边界见 [MATH.md](MATH.md)，实现见 [chirp.py](chirp.py)、[exact_emit.py](exact_emit.py)。

## 2. 数据、基准与统计单位

沿用 R2 的 20×32 二维 OFDM、三径、16-QAM、(128,64) LDPC、9 dB 公共仿真分布。
从正式 P6 的 pair06 至 pair15 载入全部十个 Axial-Parity 检查点及对应 Local-Parity 检查点。
每个模型簇使用四次 B8 新仿真，种子为 `602611190000 + 1000*i + j`，i=1..10，j=0..3。
每种条件合计 320 个 burst、5,760 个 LDPC 码块。比特、信道等真值只在推理后用于评分。

协议和源/检查点 SHA-256 在第一次新波形评分前于本次会话冻结，见 [PROTOCOL.md](PROTOCOL.md)、
[FREEZE.json](FREEZE.json)。这是会话内事前冻结，不是外部公开预注册。
三个旧开发检查点只用于集成检查，没有用它们冒充新样本。没有调节新温度、增加训练参数或重训。

导频损伤是在接收网格上将指定导频值（含其中噪声）乘 0.4 或清零，保留原 pilot mask、导频符号和
噪声声明。**这属于未显式告知接收机的数字观测损伤，不是新模拟的物理衰落/丢包过程。**
2D-LMMSE 的协方差匹配原始公共信道先验，不匹配新增清零机制；不能据此宣称优于所有匹配先验经典方法。
Fixed+Parity 是固定物理接收机，Waveform-DD 是公共模型下的经典参考，均与学习方法接收同一观测。

统计以十个“旧检查点＋新波形”簇为独立配对单位，不把同一 burst 内的 LDPC 块当成独立重复。
主要检验只有首行与内部行清零两项，枚举 2^10 符号翻转并做 Holm 校正。其有效性仍依赖配对零假设
下的符号交换性/对称性。其他条件、硬 chart、经典/局部对照均为描述性结果。

## 4. 连续复数结构、等变性与精度

连续 complex128 信号、物理波形/ICI 求解、既有 Hermitian/复数注意力和二维时间频率结构保留，
新增的中性标量权重作用于现有物理相位残差。注意力模块未改动，Local 对照在本次仅作描述，不能确立注意力优势。
在规范归一化及噪声按 |c|² 同步变化的前提下，新规则在精确算术中保持全局 C* 变换关系；
原始残差单独具有固定 ridge，不能脱离规范归一化声称尺度不变。

数值审计使用旧开发检查点 901/902/903，每个 10 种条件、27 个复增益，幅度覆盖 1e-35 至 1e20。
严格门槛同时要求 LLR 差和相对 CFR L2 差 <1e-12，且无编码硬判决翻转。

## 5. 同机器延迟与 FFT 化简

CPU：AMD EPYC 9V74 80-Core Processor。Torch 2.12.1+cpu，单线程，float64/complex128。
每种批量使用同一观测、同一 pair06 检查点，循环交错顺序，3 轮预热＋15 轮留样，表列中位数。
计时期间停止其他实验计算任务；包含内部 parity，排除仿真与最后的外部 LDPC 解码。

| 批量 | Trust / ms | Smooth / ms | Smooth + FFT 恒等化简 / ms |
|---|---:|---:|---:|
| 1 | 17.512 | 17.666 | 17.772 |
| 8 | 107.182 | 114.440 | 96.593 |
| 64 | 905.396 | 891.880 | 944.556 |

可选 FFT 化简没有显示一致的全接收机加速：B8 的中位数较低，B1 和 B64 反而较高；
B64 相对未化简 Smooth 慢约 5.91%。
该化简属于算术操作减少的实现候选，尚无稳定的系统延迟收益证据。

原始样本和四分位数见 [latency.json](results/latency.json)。这是一次机器上的短时测量，存在系统抖动；
不把局部 FFT 恒等式当作整体加速定理，也不与历史工作站的绝对毫秒数直接比较。
该文件同时保留 B1/B8/B64 下恒等化简与同一 Smooth 实现的 LLR/CFR 差、硬判决和完整解码计数。

## 7. 本次证据支持的边界

可以支持：一个具体、可微分的相位图册改造，在冻结旧权重、同一公共 R2 分布、两种指定数字导频损伤下，
相对 Trust 有经配对检验的局部 BLER 改善；另有可验证的 R2 发射数学恒等化简。

尚不能支持：全面优于硬 chart、注意力必要、未知信道族泛化、优于针对损伤重新匹配的经典最优参考、
更好的训练收敛、通过 P6 全部严格数值门槛、低精度可部署、外部独立复现，或新阶段名称本身意味着性能胜出。
下一步应在开发数据上解决弱导频浮点敏感性，并为任何改动另取未使用的新验证种子；本轮不追改算子来迎合已见结果。
