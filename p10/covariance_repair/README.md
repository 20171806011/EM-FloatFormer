# EM-FloatFormer P10 · 用未知载荷的复相关修复单径多普勒跳变

2026-11-20。范围为 P9 合成 OFDM → CP 单载波、9 dB、三径、B 帧一个导频块。这里交付一个已执行的经典接收机开发实验，以及可以判定学习注意力贡献的下一轮实验设计。原生 LDPC 结果适用于本包列出的行和种子。

## 接收机怎样决定要不要修

1. 用 A 帧公开导频估计三条路径。B 帧的物理候选包括不变和 36 个单径跳变组合。对第 r 径乘上 exp(2πiδ(t−t₀))，其余两径继续按历史演化。t₀ 为 B 帧首个循环前缀起点，时间以 N 个样点为单位。δ 网格为 ±{0.025, 0.035, 0.045, 0.055, 0.065, 0.075} cycles/N。零变化先验取 1/2，剩余 1/2 均分给 36 个组合。这个开发候选库针对已知三径和帧边界跳变，覆盖范围及先验属于设计选择。
2. 先按 B 帧第 10 行已知导频打分。然后对第 2、5、8、13、16 行未知载荷，用各候选的预测复协方差给实收波形打分。按各行得分之和与导频分数做 softmax，再将同一变化径的权重相加。帧内行号从 0 起算。由于存在离散频偏、模型失配、复合似然，实际权重是用于排序的近似权重，0.90 不具有已校准的正确率含义。
3. 保留冻结的 P9 经典 Jeffreys/Student-t 接收机输出。若某条变化径的合计权重至少为 0.90，用该径权重最高的两个频偏分别以旋转后的导频字典重新估计三径状态。对两个分支作均值与方差匹配，包括分支间均值差。这一版仍可能遗漏第三个峰或丢失混合分布的形状。
4. 在另两行未知载荷（稀疏布局中的第 0、9 行）上比较修复分支与原 P9 的协方差得分。修复分支得分更高才切换。两者共用原生 LDPC。五行选径、两行判切换，均与计入 BLER 的十一行完全分开。探针第 19 行在接收接口已遮蔽。此方案允许整帧平滑，在后到的数据参与判决时须计入接收延迟。
5. 两阶段的作用不同。导频定住绝对相位，其他数据块的复相关比较各条径的相对相位演化，最后两行检查所选变化在另一段观测上能否预测得更好。未引入额外发射导频。证据行仍携带载荷，开发实验只计另外十一行的错块。

## 未知符号为什么能用

固定某一数据行的完整信道 H，写作 y=Hx+n。原生 (128,64) LDPC 的生成矩阵上，逐一检查 32 个四比特符号投影和 496 个八比特符号对投影，其 GF(2) 秩全部为 4 和 8。均匀独立信息位经本项目的归一化 Gray 16-QAM 映射后，各符号均值为零、平均能量为一、两两独立。因此 E[xxᴴ]=I，真实二阶矩为 C=HHᴴ+N₀I。整组 32 个符号依然受编码约束。

令一个候选的正定协方差为 C，得分 s(C;y)=−yᴴC⁻¹y−log det C，C⋆ 为真实协方差。只用 E[yyᴴ]=C⋆ 就可得

$$
E[s(C_\star;y)-s(C;y)]=\operatorname{tr}(C^{-1}C_\star)-\log\det(C^{-1}C_\star)-N
=\sum_k (\lambda_k-1-\log\lambda_k)\ge 0 ,
$$

其中 λₖ 是 C⁻¹ᐟ²C⋆C⁻¹ᐟ² 的特征值，取等当且仅当 C=C⋆。该证明不要求载荷高斯。它保证正确协方差的期望得分最高，未给出任意有限样本的选径成功率。实际矩阵用 A 的路径均值代入，另在对角加入噪声和三径边际方差之和，对多行分数求和也近似处理了共享状态的不确定性。

本项目的三条不同延迟为 0、2、4 个样点。逐径相位旋转不改变每行各列贡献的平方模和，所有候选的协方差对角相同。因此只保留对角的功率评分，在归一化后必然与只用导频分权一致；脚本逐链路检验了这一点。非对角项中，同一个发射符号经不同延迟到达时带有径间相位差。不同候选若改变这些项，未知载荷便可能区分它们。所有路径同乘一个块内常相位时 C 保持不变。原生码还给出后一问题的一个独立检查：整块 16-QAM 取负对应每符号翻转两个符号位，得到的掩码违反 64 个校验中的 32 个。因此无噪声、H 可逆时，H 和 −H 对应的接收码本不相交，后续可以单独测试码本证据能否进一步处理二阶统计的盲区。

经典二阶统计盲辨识有既有文献。本方案围绕既有 P9 信道的稀疏导频、旧状态复用和未知单径跳变设计。[Tong、Xu、Kailath 1994](https://people.ece.cornell.edu/ltong/papers/TongXuKailath94IT.pdf)

## 两批运行

第一批每机制 64 条开发链路，起始种子 960261120000。仅为比较证据来源，各候选沿用 A 的路径估计，B 的导频和辅助行只参与分权。NMSE 为干净隐藏探针的总平方误差除以总信号能量。每个机制有 704 个另行留出的原生 LDPC 码块。P9 经典接收机可同场评估，但其幅度更新和读出与这个初版不同。

初版在连续条件下明显落后于 P9，于是改成有条件启用的修复分支，重新用种子 960261121000 至 960261121063 检查三种机制。各机制共用同一组种子。新方案使用同一条规则，接收机看不到机制类别。候选库没有专用的完全重置候选，原 P9 的输出负责兜底。第二批先比较完整修复与 P9；之后在已得知此主比较的条件下追加“仅用导频选径”消融。三种方法均共用评估用的原生译码器。此消融保留第 0、9 行的切换检查和相同的重估规则，只去掉五行载荷参与频偏与变化径的打分。

单径跳变的 P9 经典至完整修复的绝对 BLER 收益为 25.00 个百分点。按独立链路配对重抽样 4,000 次，探索性 95% 百分位区间 19.74 至 30.54 pp。仅导频选径的修复至完整修复另有 12.22 pp，探索性区间 7.39 至 17.33 pp。连续条件 P9 对完整修复的收益为 −0.43 pp，区间 −2.27 至 +1.14 pp。完全重置为 −0.14 pp，区间 −0.43 至 0 pp。区间未作多重比较调整。

同批 P9 至完整修复的探针 NMSE，单径跳变 0.6673 → 0.2425，连续 0.0907 → 0.0987，完全重置 0.5753 → 0.6715。完全重置 64 条中有 61 条在第一道门被提议修复，第二道门挡回其中 57 条。高权重可以代表“现有候选里最像”，并不保证候选库覆盖了真实信道。重置链路上四次切换带来的 NMSE 退步值得单列。结果仅为开发实验，两个批次、原生译码器、三个机制和固定频偏网格的边界都应保留。

## 下一轮怎样判断注意力的增量

- **独立复现与强译码。** 恢复同一冻结 strong_large，对全部 16 个共有块做交叉留出。对每个目标块，确保它只在最终译码中出现，选径与切换只用其他块。主场景、物理候选、频偏网格与预算一致。单列在线因果和整帧平滑的时延。保留现有 P9 完整解码结果作参考，同一次实验中的方法须按同一套新样本配对比较。
- **稳健性。** 对完全重置增加明确的重置竞争分支。比较候选内权重、逐行预测分数和相对重置分支的证据。用开发集冻结规则，在连续、全重置、帧中跳变、幅度超出网格的新轨迹上测误启用、探针 NMSE、BLER 和成本；保留从不切换的 P9 作为保护基线。
- **注意力的具体职责。** 为每条物理假设保留经典协方差打分。将各行观测、预测协方差和残差作为匹配输入，让一层交叉注意力在经典分数上学习各行证据的可靠性或残差。同一信息同时交给全感受野的非注意力集合网络，也保留固定逐行权重的经典版本。训练数据、候选、译码器、推理与调参预算匹配。三者吃到同样的额外未知载荷。额外读入五行波形本身的收益由上面的消融衡量。
- **预注册建议。** 主指标为单径跳变时 strong_large 共有码块 BLER 的绝对差，按链路组配对，预先估算样本量并锁定独立测试种子、训练种子、开销与多重比较规则。相比最强经典以及全局非注意力对照，若学习注意力的收益区间下界均超过建议门槛 1 pp，支持它在这一设置有独立价值。若相对经典的区间上界低于 1 pp，可排除该幅度的增量。跨越门槛则保留为未决。连续与完全重置另外验收，建议各自的退步上界低于 1 pp，同时记录探针退化。对齐破坏或证据行打乱用作机制诊断。正式实验单独报告吞吐、时延和计算预算，本次未做部署测速。

## 复现

仓库 [EM-FloatFormer，固定提交 faeea63](https://github.com/20171806011/EM-FloatFormer/tree/faeea639727aab72740cdd0a719106f83824226e)。本包不修改仓库文件。在另一个目录解压本包，将 PYTHONPATH 指向该提交的本地根目录。计算使用 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0，单线程 BLAS。第一次运行输出第一批明细，第二次输出第二批明细。

```bash
export PYTHONPATH=/absolute/path/to/EM-FloatFormer
export OPENBLAS_NUM_THREADS=1
python p10_covariance.py --links 64 --out p10_cov_results.json
python p10_repair.py
```

两份 JSON 含逐链路、逐目标块的错块记录及探针误差；可重新配对统计。第一批三个证据对照的候选、分权后的读出和参数相同。第二批的经典 P9 还使用原有的导频内状态更新。两个批次均未训练神经网络，未使用 strong_large，未执行正式盲测。
