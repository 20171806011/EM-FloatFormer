# P2-C — Complex-phase equivariance (completed)

The decision from P2-B was to test explicit physics symmetry independently of parameter-count escalation. Implemented a **2,060-parameter** complex-linear circular FIR with invariant energy-gating (`res_equiv_local`) and compared it to the 722-parameter real delay-domain unfolded shrinker and to the 38,018-parameter P1 circular CNN/log. New P2-C weights trained on P2 exploratory seeds 1201–1203, 600 steps and batch64. Same held-out synthetic frames as P2-A/B; only passive reception.

## Mathematical property proved by architecture

Let `R_phi(z)=exp(i phi)*z`. The complex FIR `C_w` is complex-linear, hence `C_w(R_phi(y))=R_phi(C_w(y))`. The gate `g(|y|^2,log noise_variance)` has real inputs invariant under the common rotation, and mixing scalars are real. Therefore, for the equivariant receiver, `Hhat(R_phi(Ypilot))=R_phi(Hhat(Ypilot))`. The QPSK equalized statistic `Ydata*conj(Hhat)/(abs(Hhat)^2+sigma^2+.01)` is invariant when pilot and data rotate together. This proves common global `U(1)` phase-equivariance, **not** data-only phase-error invariance, delay-scale invariance, or full time/frequency covariance.

## Numerical audit

For trained models (3 seeds × 3 phase angles × 512 frames), `res_equiv_local` and `res_unfold` showed max logit deviation <= 2.87e-6 and **0 hard decisions changed** on common rotations. P1 CNN/log showed maximum logit change 6.612 under the same transformation, confirming the symmetry is not built into that comparator. This is a structural test, not evidence that symmetry alone caused any BER improvement; model sizes and functions differ. Evidence: `p2c_results/phase_equivariance.csv` generated by `p2_symmetry.py`.

All three exploratory seeds favor the equivariant FIR over P1 CNN/log on both held-out channels, although this is NOT a confirmatory significance result. The equivariant receiver is still inferior to the physically informed fixed-support DFT-8 baseline by 0.925 BER percentage points on equal4 and 2.017 points on long6. The train3 difference vs P1 CNN is +0.156 points. This is an apparent efficiency/generalization tradeoff, not universal dominance.

**Stopping rule:** Do not add the proposed Conformer/attention module: the inexpensive physics-guided estimator already satisfies the narrow P2-C symmetry objective, while DFT-8 is substantially stronger; adding model complexity would obscure the issue. Freeze candidates and proceed to P2-D robustness study. Candidate for P2-E will be selected using combined exploratory results only, prior to new-seed confirmatory testing.
