# Phase 5 prospective experiment rules

Recorded before calibration and before fitting any test-seed model. A result can falsify each proposed advantage.

* The three fixed regimes are blind PA/oscillator drift, continuous super-Nyquist Doppler, and four-receiver fractional-delay wavefields. The first is the primary investment (10 independent training/evaluation pairs). The other two use five pairs apiece. Use all pairs in their declared order. Each training seed fits four separate networks with the same fresh bursts and initialization seed. The parameter-free unrolled solver and every classical receiver run on the same test bursts. All checkpoints are final iterates.
* Calibration uses only the nominal iterative PA canceller in R1 and the iterative waveform-DD receivers in R2/R3. Use the grid −8 to 32 dB by 4 dB with common random numbers, 24 development bursts/point. Refine by 1 dB within ±3 dB of the coarse point closest to 20% BLER on a second 64-burst stream, then validate on 96 fresh bursts. Ties favor lower SNR. A failed 5–35% validation stops that regime before training. Preserve failures. Report these named references again on the fresh test set, including misses. Other arms may lie outside the reference waterfall.
* Train 192 Adam steps, batch four, step size 0.006, mean BCE on all coded bits before decoding. Validate on 16 fixed, independent bursts at steps 0, 48, 96, 144, 192. Record the training trace and do not select using validation or test ranks. Record whether the trace supports convergence. Use 80 new test bursts per seed. There is one independent statistical unit per pair of independently drawn weights and test stream. Shared blocks within one burst are not independent replicates.
* Record integer pre-decode coded-bit errors, post-decode information-bit errors and erroneous 64-information-bit blocks. Report the ratio of summed squared channel error to summed squared ideal propagation diagonal magnitude, in dB. All receivers use the same P4 systematic (128,64) code, positive-for-one LLRs, 12 rounds maximum of normalized min-sum with 0.75 normalization. Data REs in time/frequency order contain contiguous complete codewords.
* The primary family is full-model BLER versus each of the three preselected nonprivileged calibration references. The ablation family contains full versus each of four controls (pure physics, matched local, single physical update/no iterative feedback, no gauge) in each regime. Use exhaustive two-sided sign-flips of the integer paired error differences with ties included, followed by step-down Holm correction within the named family. Remaining baseline contrasts are descriptive. For the separate two-test kernel family compare trained versus initialization and trained versus key permutation, with one mean across frames/layers per seed. A five-pair two-sided test has minimum p=0.0625.
* Probe actual R3 attention on eight fresh bursts, identical before and after fitting. Within each burst and attention layer, compute Pearson correlation over off-diagonal coordinate pairs against the magnitude of the conditional path covariance supplied only to the scorer. For the null permute key coordinates jointly for every query using eight fixed random permutations per layer. Report the mean of the individual correlations, as well as layer records. Training uses no covariance targets. A positive score at initialization alone cannot establish acquisition during training.
* Record trainable real degrees of freedom and inference-only CPU wall time for batches 1 and 64, one PyTorch thread, three warmups, 11 timed repetitions, median and interquartile range. Exclude simulation, terminal LDPC scoring and model construction. Include the internal six-round code-feedback pass in the R2/R3 waveform-DD timings. Run latency separately from the fitting workers. The exposed simulator input is the received signal, pilot geometry/values, noise variance and regime. Only the designated PA genie can receive true PA coefficients, and it is a privileged algorithmic comparator.
* RNG seeds in the runner are partitioned by regime, stream, replicate and batch. SNR does not change the simulator draw within a calibration sweep. Do not adjust models or budgets after held-out results. Source hashes and calibrated SNRs are saved before the formal fits.

## Amendment after the first complete run

An adversarial first-pilot-row erasure exposed a C* phase-reference defect outside the stochastic test distribution. An entirely zero waveform also produced non-neutral, scale-dependent LLR magnitudes. The original source, protocol, calibration, fits, traces, test counts and statistics are preserved in `revisions/first_run.zip`. The amendment changes the undefined phase reference, scale fallback and zero-information handling. The original seed allocation, calibration selection rule, receiver families, objective, budget and decision rules apply. Repeat all calibrations, all 80 fits, all 165 held-out rows, the three trained-checkpoint audits and separate latency runs. Compare every final state tensor and all counts against the archive. Report any changes, including discrepancies. The original results were already known when the numerical defect was found. The repeated run uses the same realizations and is not an additional independent replication.
